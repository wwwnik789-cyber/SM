# Логотипы соцсетей, мессенджеров и площадок — версия, которая открывается везде

Исходный лист `public/media/social-logos.svg` (ветка `arena/ccaea285-sm`) собран на `<symbol>` + `<use href="…">`
(синтаксис SVG 2). Illustrator, CorelDRAW, старые Inkscape, просмотрщики Windows и часть конвертеров
такие ссылки не понимают: подписи (обычные кривые) видны, а самих логотипов нет.

Здесь та же графика без `<symbol>`/`<use>`: каждый логотип вставлен напрямую, градиенты и маски — в общем `<defs>`.
Внешний вид 1:1 с исходником. В комплект добавлен **MAX** — лист стал 5 × 2.

| Файл | Для чего |
|------|----------|
| `social-logos_flat.svg` | Весь лист 5×2 (1600×480) с подписями, вектор — для Illustrator / Corel / Figma / браузера |
| `social-logos.png` | Весь лист, 3200×960, прозрачный фон |
| `social-logos_white.jpg` | Весь лист на белом фоне (если просмотрщик показывает прозрачность чёрным) |
| `single/*.svg` | Каждый логотип отдельно, вектор |
| `single/*.png` | Каждый логотип отдельно, 512 px, прозрачный фон |

Логотипы: ВКонтакте, Pinterest, Telegram, **MAX**, Дзен, YouTube, RUTUBE, Яндекс Карты, Яндекс Услуги, Авито.

**MAX** (`single/max.*`): белый знак-«облачко» — контур с сайта max.ru; плашка — градиент приложения
голубой → синий → фиолетовый (`#20C7FF → #3A58FF → #A23BFF`), собрана по иконке приложения
(официального векторного пресс-кита в открытом доступе нет). Подпись «MAX» набрана тем же DejaVu Sans 20 px
и переведена в кривые, как остальные. Права на логотипы и товарные знаки принадлежат их владельцам.

Пересборка из исходника:
```bash
python3 scripts/social/flatten_social_logos.py путь/к/social-logos.svg
```
