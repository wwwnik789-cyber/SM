## Оригинальный логотип (предоставленный клиентом)
- `SM logo name ten с тенью.png` — основной полный логотип с 3D-кубом SM, надписью SMPRODUCTION (S и M золотые, остальные буквы белые) и подписью "event branding decor" белым цветом под ним.
![Основной логотип SM Production](./SM%20logo%20name%20ten%20с%20тенью.png)

### Фирменные цвета из оригинального логотипа:
- Золотой/охра для букв SM: `#D4A027`
- Белый основной текст: `#FFFFFF`
- Фон темный/прозрачный, рекомендуемые фоны для баннеров:
  - Темно-серый матовый: #1a1a1a
  - Графитовый: #2D2D2D
  - Черный матовый: #0A0A0A

## Дополнительные векторные версии (в разработке):
- `favicon.svg` — иконка 64x64 для вкладки, квадратная с монограммой SM
- `logo_main_dark.svg` — основной логотип для темной темы (горизонтальный, SM + Production)
- `logo_main_light.svg` — основной логотип для светлой темы
- `logo_monogram.svg` — только монограмма SM (для маленьких размеров, иконки)
- `logo_horizontal_short.svg` — SM + подпись (компактный горизонтальный)
- `logo_vertical.svg` — вертикальная версия для шапки/футеров
