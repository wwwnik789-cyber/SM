# Оклейка поверхностей на мероприятиях

Серия из восьми концептуальных визуализаций с вымышленными брендами. Формат каждого изображения — 1200×675 px.

## Сюжеты

1. `01-conference-registration.jpg` — оклейка модульной стойки регистрации и фоновой стены конференции NEXORA.
2. `02-exhibition-stand-wrap.jpg` — оформление стен, технической двери и ресепшн выставочного стенда VECTARA.
3. `03-stage-and-lectern.jpg` — оклейка фасада сцены, декораций и трибуны конференции ALTIS.
4. `04-glass-event-navigation.jpg` — полупрозрачная, матирующая и навигационная оклейка стеклянной входной группы LUMORA.
5. `05-product-launch-plinths.jpg` — оформление демонстрационных подиумов и стойки презентации NOVARO.
6. `06-floor-graphics-wayfinding.jpg` — временная противоскользящая напольная навигация FORVIA с сохранением свободной тактильной полосы.
7. `07-column-wrap-activation.jpg` — оклейка круглых колонн и мобильных элементов активации PULSERA.
8. `08-gala-bar-wrap.jpg` — оформление модульных барных стоек и платформы делового вечера AURIX.

Названия и фирменные стили созданы только для визуализации и не обозначают реальные проекты SM Production. Перед производством необходимо проверить материал основания, выбрать совместимую съёмную плёнку и ламинат, согласовать пожарные требования, пути эвакуации, доступность, нагрузку на напольную графику и правила площадки.
