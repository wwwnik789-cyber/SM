# TSUM Beauty Days — стойка в интерьерах универмага

**Концепт-визуализации, не фотографии установленной работы.** Стойка на кадрах —
готовый рендер по чертежу, интерьеры — сгенерированные. Ни один кадр не снят на
площадке.

## Что изменилось после складских фото

Первая версия собиралась из фотографий со склада: стойка вырезалась из реального
снимка. Честно по графике, но темно и плоско — на кадрах она читалась как
наклейка. Получив нормальный рендер, пересобрал всё на нём: чистые линии, окно с
шарами, объём и правильная графика «TSUM BEAUTY DAYS».

Складские снимки остались в `../tsum-beauty-days-2026/source/` — они годятся как
съёмка конструкции, но не как источник картинки.

## Что пришлось исправить в рендере

Рендер снят в студии на белом и с одной ошибкой: **корпус повёрнут примерно на
7°**, нижняя кромка уходит по `y = 0.121·x`. На белом это незаметно, в зале стойка
тонула бы в пол углом. Наклон снят сдвигом строк по этой прямой (замер по 87
точкам нижней кромки, остаток 0,84 px), а не поворотом — вертикали остаются
вертикальными.

Дальше:

- маска по насыщенности: фон белый, стойка оранжевая, граница чистая;
- мягкая серая тень на «столе» под стойкой в маску не попадает — своя тень
  считается отдельно.

## Масштаб — расчётом, а не на глаз

Для предмета высотой `h` при камере на высоте `c`:

```
высота на кадре = (h / c) · (y_пола − y_горизонта)
```

Стойка 1800 мм, камера 1600 мм → коэффициент **1,125**. Линия глаз в каждом фоне
взята по сходу перспективы (подоконники, прилавки, балюстрада), а не назначена.

| Кадр | Линия глаз | Низ стойки | Высота на кадре |
|---|---|---|---|
| 01 зал с окнами | 60,0 % | 90,0 % | 33,7 % кадра |
| 02 гости на приёме | 52,0 % | 93,0 % | 46,1 % |
| 03 атриум | 61,0 % | 90,5 % | 33,2 % |

Проверка посадки по пикселям: на кадре 03 расчёт даёт 348 px, замер по картинке —
343 px (расхождение 1,4 %). Совпадение и означает, что стойка стоит в геометрии
зала, а не «приклеена» сверху.

Кадр 04 — кроп кадра 02 с той же точки съёмки: эквивалент длинного объектива,
перспектива не меняется.

## Почему вторая версия перестала выглядеть наклейкой

Четыре причины, все лечились по отдельности:

1. **Резкость.** Спрайт уменьшался в 3–4 раза и оставался резче фона. Размытие
   привязано к коэффициенту уменьшения, а не задано константой.
2. **Цвет.** Студийный рендер холоднее и насыщеннее зала. Яркость и насыщенность
   подтягиваются к локальному окружению (только светлота — поканальная подгонка
   уводила белые буквы в бирюзу, это отброшено).
3. **Свет.** Верх ловит свет с потолка, низ уходит в тень: спад к полу 20–42 %
   плюс затемнение последних 10 % высоты у самого стыка с полом.
4. **Опоры.** Контактная тень узкая и плотная прямо под корпусом, падающая —
   короткая и широкая (свет верхний), отражение в полу тихое и сильно размытое.
   Плюс отражение окружения на ламинате и AO по контуру.

## Как собрано

```bash
python -m venv .venv && .venv/bin/pip install pillow numpy scipy
.venv/bin/python visualizations/tsum-mall-2026/compose.py
```

`compose.py` вырезает стойку из `source/render-concept.jpg`, снимает наклон,
подгоняет свет и цвет под каждую сцену и собирает кадры. Фоны берутся из
`../tsum-beauty-days-2026/raw/`.

## Границы достоверности

- Габариты 870 × 1800 × 650 мм — по чертежу, не по картинке.
- Интерьеры сгенерированы: это не ЦУМ, не ГУМ и не конкретная площадка, а тип
  пространства.
- Люди на кадрах 02 и 04 — из фоновой фотографии, к проекту отношения не имеют.
- Даты «08.10 – 11.10» и логотип «ЦУМ» нанесены на сам рендер стойки; в макетах
  под печать их нужно менять на актуальные.
