# Визуализация баннера на телебашне «Аником Арена»

Баннер установлен в отмеченной заказчиком зоне: на нижней фронтальной плоскости будки, строго под окнами. Визуализирован плоский скрытый каркас глубиной около 25–35 мм — без видимых опор, люверсов, тросов и внешних креплений.

## Ракурсы

- [`01-front-view.jpg`](./01-front-view.jpg) — точная фронтальная фотопривязка к исходному снимку;
- [`02-left-three-quarter.jpg`](./02-left-three-quarter.jpg) — левый трёхчетвертной ракурс;
- [`03-right-three-quarter.jpg`](./03-right-three-quarter.jpg) — правый трёхчетвертной ракурс с более заметной лестницей;
- [`adapted-horizontal-artwork.png`](./adapted-horizontal-artwork.png) — адаптация квадратного макета под горизонтальную монтажную область.

## Как адаптирован макет

Исходный PDF имеет квадратный формат, а отмеченная плоскость — горизонтальный прямоугольник. Поэтому макет не растянут целиком:

- центральный круг и логотип сохранены с равномерным масштабированием;
- тёмно-синий фон и боковые геометрические поля продолжены по ширине;
- коралловая рамка перестроена под фактические пропорции лицевой плоскости;
- во всех трёх ракурсах после перспективной генерации повторно наложен один и тот же точный файл artwork.

## Важно

Фронтальный ракурс основан непосредственно на исходной фотографии. Левый и правый ракурсы — фотореалистичные реконструкции по одному исходному снимку, поэтому они предназначены для согласования внешнего вида, а не для инженерных замеров конструкции.

## Исходники и пересборка

В `source/` сохранены исходное фото, фото с красной разметкой и предоставленный PDF-макет.

```bash
python -m venv .venv
.venv/bin/pip install -r visualizations/anikom-arena-tv-tower-banner-mockups/requirements.txt
.venv/bin/python visualizations/anikom-arena-tv-tower-banner-mockups/build_front_mockup.py
.venv/bin/python visualizations/anikom-arena-tv-tower-banner-mockups/apply_exact_artwork.py
```
