Серия из восьми концептуальных визуализаций с вымышленными брендами. Формат каждого изображения — 1200×675 px.

Названия и фирменные стили созданы только для визуализации и не обозначают реальные проекты SM Production. Перед производством необходимо выполнить замеры, проверить тип стекла, выбрать совместимую плёнку, согласовать зоны прозрачности, пожарные требования и правила конкретного торгового центра.
