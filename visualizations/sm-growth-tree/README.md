# Дерево роста SM — инфографика 1:2 (SVG)

Вертикальная векторная схема (viewBox 1000×2000) о том, как SM-Production растёт во времени.
Фирменная палитра и логотип из баннера SM (логотип векторизован из `assets/brand/sm-logo-extracted.png`).

| Файл | Для чего |
|------|----------|
| `sm-growth-tree.svg` | Основной: живой текст и встроенные шрифты Unbounded/Manrope (только нужные глифы), анимация «соков» — золотые частицы идут от корней к кроне (видно в браузере) |
| `sm-growth-tree_outlined.svg` | Текст в кривых: для печати, Illustrator, Figma (не нужны шрифты) |
| `sm-growth-tree_preview.png` | Превью 1500×3000 |

## Пласты (снизу вверх)
1. **Корни — каналы продвижения и роста**: SEO, Яндекс Директ, Яндекс Бизнес/Карты, ВКонтакте, Telegram-канал,
   Rutube (SM-Media), Pinterest, блог, отзывы, сарафан и повторные заказы, партнёрство с агентствами, тендеры и выставки.
2. **Ствол — услуги, на которых зарабатываем**: 12 карточек; основные (комплексное оформление, имиджевые фотозоны,
   оформление сцен) выделены золотом. У каждой услуги шкала из 5 делений: **насколько подробно она описана на сайте**.
   Шкала считается автоматически по текстам `src/data/services.js` — по одному баллу за каждое:
   текст ≥ 300 символов · ≥ 450 символов · указана цена · ≥ 4 преимуществ · ≥ 2 абзацев подробного описания.
   Для «Собственного производства» и «Аренды и SM-Media» оценка задана вручную по тем же критериям.
3. **Ветви — активы компании**: в центре сайт sm-production.ru, слева аналитика (amoCRM, Яндекс Метрика,
   аналитика сайта, аналитика телефонии, сквозная аналитика), справа каналы связи (почта, телефония Билайн,
   Telegram, MAX, заявки с сайта).
4. **Крона — клиенты и проекты**: ключевые клиенты и проекты портфолио по годам (2023 → 2026, крона растёт вверх),
   данные из `src/data/portfolio.js`.

Слева — ось «время · рост компании».

## Как поменять
Все тексты — списки в начале `scripts/tree/sm_growth_tree.py` (`CLIENTS`, `ANALYTICS`, `CONTACTS`, `SERVICES`,
`ROOTS`, `PROJECT_SHORT`). Пересборка:
```bash
pip install -r scripts/tree/requirements.txt
python3 scripts/tree/sm_growth_tree.py
```
