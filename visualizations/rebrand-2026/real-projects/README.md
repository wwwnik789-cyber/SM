# Ребрендинг реальных фото реализованных проектов

Фотографии реальных конструкций SM Production перекрашены в фирменный стиль
(мастер-баннер `assets/brand/sm-banner-master.jpg`). Фото настоящие, нейросеть
сцены не перерисовывала: заменены только брендируемые поверхности.

| Результат | Сравнение | Что заменено |
|-----------|-----------|--------------|
| `sm-real-podium-runway.jpg` | `sm-real-podium-runway_before-after.jpg` | Подиум: красное покрытие → графитово-синее; фиолетовая боковина → фирменная полоса с логотипами и золотым кантом; салатовый торец → баннер с логотипом; дальние торцы → тёмно-синие |
| `sm-real-stage-cache-riser.jpg` | `sm-real-stage-cache-riser_before-after.jpg` | Сцена: бежевое каше → фирменный фон; контент экрана → баннер SM; раус → полоса с логотипами (+ отражение в глянцевом полу); правый торец каше → тёмно-синий |
| `sm-real-navigation-pillar.jpg` | `sm-real-navigation-pillar_before-after.jpg` | Стела: щит → баннер с логотипом; указатели → фирменные таблички (тёмно-синяя, золотая стрелка, светлая) с текстами на русском |
| `sm-real-projects-overview.jpg` | — | Обзорный лист трёх проектов |

Исходники (уменьшены до 2400 px по длинной стороне) — `originals/`.

## Как это сделано
- **Поверхности**: по цвету (подиум: красный, фиолетовый, салатовый; красная стрелка),
  по контуру + цвету (каше, щит), по углам с увеличенных фрагментов (раус, таблички).
- **Перспектива и пропорции**: углы поверхностей — пересечения прямых по кромкам;
  реальные пропорции (например, боковина подиума ≈ 22:1) восстановлены через
  фокусное расстояние камеры, найденное по точкам схода. Проверка: экран на фото
  сцены вычислен как 1.78 = 16:9.
- **Свет**: тени, складки и блики берутся с исходной поверхности, причём текст и
  логотипы старого бренда из карты света исключаются, чтобы они не проступали.
- **Окклюзия**: всё, что стоит перед конструкцией (монитор у рауса, стойка стелы,
  тень указателя на щите), сохраняется.
- **Шрифты табличек**: Unbounded + Manrope (фирменные, OFL) — `scripts/rebrand/fonts/`.

## Пересборка
```bash
pip install -r scripts/rebrand/requirements.txt
python3 scripts/rebrand/real_projects.py
```
Тексты табличек меняются в функциях `sign_top`, `sign_arrow` и `sign_bottom` в
`scripts/rebrand/real_projects.py`.
