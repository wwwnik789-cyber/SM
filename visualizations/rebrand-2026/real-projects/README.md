## Как это сделано
- **Поверхности**: по цвету (подиум: красный, фиолетовый, салатовый; красная стрелка),
  по контуру + цвету (каше, щит), по углам с увеличенных фрагментов (раус, таблички).
- **Перспектива и пропорции**: углы поверхностей — пересечения прямых по кромкам;
  реальные пропорции (например, боковина подиума ≈ 22:1) восстановлены через
  фокусное расстояние камеры, найденное по точкам схода. Проверка: экран на фото
  сцены вычислен как 1.78 = 16:9.
- **Свет**: тени, складки и блики берутся с исходной поверхности, причём текст и
  логотипы старого бренда из карты света исключаются, чтобы они не проступали.
- **Окклюзия**: всё, что стоит перед конструкцией (монитор у рауса, стойка стелы,
  тень указателя на щите), сохраняется.
- **Шрифты табличек**: Unbounded + Manrope (фирменные, OFL) — `scripts/rebrand/fonts/`.

## Пересборка
```bash
pip install -r scripts/rebrand/requirements.txt
python3 scripts/rebrand/real_projects.py                       # всё
python3 scripts/rebrand/real_projects.py sm-ad-led-bars-gift   # одна работа
```
Тексты креатива (заголовок, подпись, телефон, сайт) и кадрирование фото — в функции `creative()`.
Тексты табличек меняются в функциях `sign_top`, `sign_arrow` и `sign_bottom` в
`scripts/rebrand/real_projects.py`.
