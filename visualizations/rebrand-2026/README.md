## Почему логотип точный

Генераторы изображений искажают тонкие линии куба SM, поэтому логотип **не
рисуется нейросетью**:

1. Сгенерированы фотореалистичные подложки (`_plates/`), у которых лицевая
   поверхность залита хромакеем `#00FF00`.
2. Скрипт `scripts/rebrand/composite.py` находит поверхность, вычисляет 4 угла
   (если угол перекрыт трибуной/стойкой — по пересечению прямых видимых кромок)
   и натягивает макет с перспективой.
3. Освещение сцены (яркость зелёного) переносится на печать, предметы и люди перед
   конструкцией сохраняются, зелёные отсветы на полу перекрашиваются в синий.

В макетах используются исходные пиксели баннера: кубик, буквы и слоган совпадают
с оригиналом.

## Как добавить новую конструкцию

1. Сгенерируйте подложку с лицевой поверхностью цвета `#00FF00` (без текста и
   логотипов) и положите её в `_plates/<имя>.jpg`.
2. Добавьте строку в `SCENES` в `scripts/rebrand/composite.py`: имя результата и
   макет (из `FORMATS` в `scripts/rebrand/layouts.py`; новый формат добавляется
   одной строкой с соотношением сторон).
3. Запустите:

```bash
pip install -r scripts/rebrand/requirements.txt
python3 scripts/rebrand/composite.py          # макеты + все визуализации
python3 scripts/rebrand/composite.py --debug  # + контроль углов в .cache/rebrand-debug
```

Чтобы показать конструкцию с логотипом клиента, замените `sm-banner-master.jpg`
на макет клиента и перезапустите скрипт.
