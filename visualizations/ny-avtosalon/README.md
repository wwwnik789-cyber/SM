### Технические детали, которые видны в кадре

- **Профиль:** алюминий 40 мм, чёрный матовый порошок; углы на усиливающих уголках, саморезы впотай.
- **Рассеиватель:** акрил 3 мм opal, LED-лента 3000 K (на холодной стороне 4000 K), блок питания в опорной плите.
- **Стойки:** высота 2000 мм, опорная плита 500×350×8 мм с четырьмя регулируемыми ножками — компенсируют неровности пола.
- **Подвесы:** трос 2 мм + зажим, питание по потолку, при необходимости — балласт на полу.
- **Настенный монтаж:** кронштейны в стену, кабель-канал в цвет стены, вывод к ближайшей розетке.
- **Яркость:** подобрана так, чтобы не давать пересветов на кузове и не слепить камеры видеонаблюдения.

## Логика декора

Единая система, которая масштабируется на любое количество салонов сети:

1. **Световые линии по фризу/стенам** — «скелет» оформления, задаёт ритм и читаемость с расстояния.
2. **Неоновые фигуры** (снежинки, ключ, контур авто, кольцо, тоннель) — акценты, которые попадают в кадр.
3. **Иней + ёлки в белых кашпо** — зимняя фактура, спокойная и премиальная.
4. **Хром, зеркальные шары, боксы** — «дорогой» Новый год без пестроты, безопасно рядом с автомобилями.
5. **Тёплый свет 2700–3000 K + ледяной голубой 6000–8000 K** — пара, которая работает с любым корпоративным цветом дилера.

## Оборудование и монтаж

| Элемент | Технология | Плюсы |
|---|---|---|
| Гибкий неон (flexible LED neon) | 12/24 В, подложка ПВХ/акрил | безопасен рядом с гостями и авто, гнётся по контуру, ресурс ~50 000 ч |
| Уличные линии и арка | неон IP65 в алюминиевом профиле | морозостойкость, скрытая проводка, монтаж с автовышки |
| Скульптурные фигуры | фрезеровка акрила + контурный неон | читаются на фото, можно перевозить между салонами |
| Световые надписи («2027») | неон на подложке, регулируемая яркость | лёгкая замена цифр к следующему сезону |
| Подвесное кольцо | гнутый алюминий + тросы | крепление к существующим точкам, без сверления перекрытий |
| Ёлки | искусственные, в инее, кашпо с подсветкой | не осыпаются, пожаробезопасны, хранятся до следующего года |

**Сроки:** проектирование и производство 10–14 рабочих дней, монтаж всего салона — 1–2 ночные смены (чтобы не останавливать работу шоурума). Демонтаж — 1 смена, элементы уходят на хранение.

## Как использовать

1. **КП для дилерских сетей** — отправляйте галерею `index.html` вместе со сметой: пять зон = пять опций апселла.
2. **Сайт** — блок «Новогоднее оформление автосалонов» в разделе B2B / оформление мероприятий.
3. **Соцсети** — карусель по зонам с подписью «собираем Новый год для салона как конструктор».
4. **Сезонность** — лучшее окно продаж: сентябрь–ноябрь, когда дилеры планируют бюджет на декабрь.
5. **Масштабирование** — один дизайн-код на все салоны сети: элементы тиражируются, меняется только брендирование зоны 05.
