# Дополнительные новогодние визуализации без логотипа

Четыре концептуальные визуализации оформления кафе изделиями из вспененного ПВХ. На изображениях не используется логотип или фирменный стиль SM Production. Формат каждого файла — 1200×675 px.

## Файлы

1. `05-window-display.jpg` — многослойная новогодняя композиция в витрине кафе.
2. `06-pickup-zone.jpg` — сезонное оформление стойки выдачи и настольные POS-элементы.
3. `07-seating-partition.jpg` — зонирующая конструкция и подвесной декор в зоне столиков.
4. `08-gift-display.jpg` — компактная новогодняя выкладка рядом с торговой полкой.

Это визуальные концепции, а не фотографии реализованных проектов. Конструктив, толщина материалов, крепления и пожарные требования уточняются после обследования площадки.
