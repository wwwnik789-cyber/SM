# Новогоднее оформление кафе из ПВХ

Серия из четырёх концептуальных визуализаций SM Production. Формат каждого файла — 1200×675 px.

## Сюжеты

1. `01-cafe-entrance.jpg` — входная группа: многослойные силуэты елей, плоские украшения, брендированные панели и переносной штендер.
2. `02-counter-branding.jpg` — зона заказа: подвесной декор, фриз из вырезанных элементов, брендирование стойки и настольные POS-материалы.
3. `03-photozone.jpg` — компактная фотозона в работающем кафе: фон, городские и новогодние силуэты, скамья и брендированная лицевая панель.
4. `04-window-and-tables.jpg` — зона у витрины: сборная ёлка, подвесные элементы, настольные таблички и навигационный указатель.

Визуализации показывают возможное применение печатного и фрезерованного вспененного ПВХ в сезонном оформлении. Они не являются фотографиями реализованных проектов или подтверждёнными кейсами. Толщина материала, конструктив, крепления, пожарные требования и способ монтажа должны определяться после обследования площадки.
