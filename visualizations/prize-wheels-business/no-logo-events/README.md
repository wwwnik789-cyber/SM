# Колесо фортуны для мероприятий и выставок

Серия из восьми концептуальных визуализаций применения колеса фортуны в бизнес-мероприятиях. Все изображения выполнены без логотипов и фирменного стиля SM Production. Формат каждого файла — 1200×675 px.

## Сюжеты

1. `01-conference-registration.jpg` — интерактив в зоне регистрации деловой конференции.
2. `02-trade-show-tabletop.jpg` — компактное настольное колесо на выставочном стенде.
3. `03-product-launch.jpg` — напольная конструкция на презентации продукта.
4. `04-career-fair.jpg` — механика вовлечения посетителей ярмарки вакансий.
5. `05-corporate-evening.jpg` — розыгрыш во время корпоративного вечера.
6. `06-exhibition-wall-wheel.jpg` — колесо, встроенное в стену выставочного стенда.
7. `07-client-workshop.jpg` — интерактив на клиентском воркшопе.
8. `08-awards-networking.jpg` — розыгрыш в networking-зоне деловой премии.

Визуализации являются концепциями, а не фотографиями реализованных проектов. Диаметр колеса, материал лицевой панели, конструкция опоры, подшипник, стопор, указатель и устойчивость рассчитываются под конкретную площадку и сценарий использования.
