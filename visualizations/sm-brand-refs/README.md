# Эталонные референсы фирменного стиля SM Production

Фото реальных рекламных конструкций SM — используются как образец при перебрендировании визуализаций из присылаемых фотографий.

## Файлы

- **`presswall-venue.jpg`** — пресс-волл на ферменном каркасе в помещении площадки.
- **`presswall-autodealer.jpg`** — пресс-волл в автосалоне.
- **`presswall-render-lobby.jpg`** — пресс-волл в светлом лобби (чистый ракурс).
- **`presswall-office-lobby.jpg`** — пресс-волл в офисном лобби со стеклянными перегородками.
- **`rollup-lobby.jpg`** — ролл-ап в светлом лобби.

## Что сохранять при перебрендировании

1. **Фон:** глубокий тёмно-синий (navy) с переливом low-poly граней — треугольные фацеты разных оттенков синего.
2. **Графика:** белая «созвездная» сетка — узлы-точки, соединённые тонкими линиями, разной плотности по полю.
3. **Логотип:** белый линейный куб (изометрия, скетч-стиль) по центру верхней трети.
4. **Шрифтовой блок:** `SMPRODUCTION` — «SM» оранжевое, «PRODUCTION» белое; ниже строка `event branding decor` светло-серым, строчными.
5. **Конструкции:** пресс-воллы на металлическом ферменном каркасе (joker/tritix) и ролл-апы; фактура и освещение исходной сцены сохраняются.

## Приём работы

Вход: фото чужой/старой конструкции → выход: та же сцена, тот же ракурс и конструктив, но полотно заменено на фирменное SM-оформление из этого набора.
