# Широкий фон SM Production — синий технологичный стиль

Один масштабируемый векторный фон для широкого интерьерного или сценического баннера. Логотип и текст намеренно отсутствуют — их можно добавить поверх спокойной центральной зоны.

## Производственный файл

`sm-production-blue-tech-background-6000x2000.svg`

- итоговый размер артборда: **6000×2000 мм**;
- пропорция: **3:1**;
- масштаб: **1:1**;
- полностью векторная графика;
- без растровых вставок;
- без текстовых объектов и зависимости от шрифтов;
- без логотипа;
- без эффектов размытия, которые могли бы растрироваться в RIP.

## Композиция

- глубокий тёмно-синий градиент;
- голубые и ледяные световые линии;
- геометрические грани по краям;
- технологическая сетка, узлы и траектории;
- спокойная центральная зона под логотип и короткий слоган;
- графика уходит за края артборда, поэтому по периметру нет белых полей.

Центральная рекомендуемая зона под логотип — ориентировочно **2100×1100 мм**. Внутри SVG она находится в скрытом техническом слое `GUIDES — DO NOT PRINT`.

## Слои SVG

- `BACKGROUND` — основной фон;
- `TECH GRAPHICS` — геометрия, сетки и световые линии;
- `GUIDES — DO NOT PRINT` — скрытая рамка итогового формата и безопасная центральная зона.

Перед передачей в печать технический слой нужно оставить скрытым или удалить.

## Подготовка к печати

1. Добавить логотип в векторе поверх центральной зоны.
2. Перевести шрифты слогана в кривые, если добавляется текст.
3. Преобразовать RGB-цвета в CMYK по ICC-профилю конкретного принтера и материала.
4. Уточнить у производства необходимость вылетов. В текущем файле артборд соответствует чистовому размеру 6000×2000 мм; вылеты следует добавить по требованиям конкретного подрядчика.
5. При необходимости сохранить копию в масштабе 1:10 — исходный SVG масштабируется без потери качества.
6. Сделать цветопробу, поскольку глубокие синие оттенки заметно зависят от профиля, материала и режима печати.

`preview-1200x400.png` предназначен только для просмотра и не является печатным макетом.
