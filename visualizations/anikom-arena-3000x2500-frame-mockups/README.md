# Визуализации баннеров 3000 × 2500 мм на скрытом каркасе

Четыре концепции «Аником Арены» показаны на одной и той же реалистичной конструкции рядом с футбольным полем. Одинаковые ракурс, масштаб и освещение позволяют сравнивать именно дизайн, а не различия мокапов.

## Как показана конструкция

- размер лицевой плоскости: **300 × 250 см**, пропорция 1,2:1;
- брус и силовой каркас полностью находятся за полотном;
- лицевая сторона не имеет видимых стоек, рам, ножек, раскосов, люверсов, тросов и крепежа;
- на правом ребре видна только минимальная толщина конструкции около 40–60 мм;
- печать продолжается на узкую боковую кромку, поэтому каркас остаётся скрытым;
- опора и балласт предполагаются с тыльной стороны и в визуализации не выступают за фасад.

Все четыре утверждённых векторных макета после создания фотореалистичной сцены наложены повторно точной перспективной проекцией. Поэтому логотипы и надписи не перерисованы генеративной моделью и соответствуют исходным SVG.

## Важно

Это визуализация внешнего вида, а не инженерный чертёж. Толщину бруса, схему раскосов, балласт и ветровую нагрузку необходимо рассчитывать отдельно под место установки.

## Пересборка

```bash
python -m venv .venv
.venv/bin/pip install -r visualizations/anikom-arena-3000x2500-frame-mockups/requirements.txt
.venv/bin/python visualizations/anikom-arena-3000x2500-frame-mockups/build_mockups.py
```

Скрипт использует точные SVG из `banners/anikom-arena-3000x2500-concepts/` и чистую базовую фотографию из `source/`.
