# Визуализации ёлочных игрушек из ПВХ — SM Production

Серия из четырёх горизонтальных визуализаций по референсу заказчика. Показаны плоские фигурные игрушки из ПВХ с полноцветной печатью, чистой белой кромкой и логотипом SM Production.

## Файлы

1. `01-studio-size-range-sm.jpg` — предметная линейка из пяти форм и размеров: от небольшой игрушки до крупного акцентного элемента;
2. `02-office-tree-different-sizes-sm.jpg` — игрушки разных размеров на живой ёлке в современном офисе;
3. `03-led-acrylic-tree-gift-zone-sm.jpg` — световая акриловая ёлка с игрушками и подарочной зоной;
4. `04-production-quality-check-sm.jpg` — набор игрушек разных размеров на производственном столе во время контроля качества.

## Параметры

- формат каждого изображения: **1200×675 px**;
- ориентация: горизонтальная, 16:9;
- формы: шары, звёзды, варежки, носки и леденцы;
- цветовая гамма: синий, фиолетовый, коралловый, зелёный и ледяной голубой;
- логотипы нанесены отдельным контролируемым слоем из фирменного исходника, чтобы избежать искажения знака.

## Показанный диапазон размеров

В композициях визуально представлены изделия примерно от **70–80 мм до 350–400 мм**. Соотношение размеров является демонстрационным и не заменяет технический чертёж.

Перед реальным производством необходимо отдельно согласовать:

- точные размеры каждой формы;
- толщину ПВХ;
- технологические отверстия и подвесы;
- вылеты печати и контуры реза;
- прочность узких участков;
- способ монтажа крупных элементов.

Изображения предназначены для презентаций, сайта и социальных сетей. Это концептуальные визуализации, а не фотографии реализованного проекта.
