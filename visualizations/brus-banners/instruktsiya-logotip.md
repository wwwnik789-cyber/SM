# Инструкция по доводке визуализаций до идеала в Photoshop (1 минута)
Чтобы на 100% избежать искажений оригинального логотипа, достаточно наложить его на готовые рендеры одним слоем в Photoshop:

### Шаги:
1. Откройте нужный рендер брус-баннера в Photoshop
2. Перетащите файл `SM logo name ten с тенью.png` на файл рендера
3. Нажмите `Ctrl+T` (свободное трансформирование), зажмите Shift чтобы сохранить пропорции и уменьшите/увеличьте логотип до нужного размера
4. Переместите слой с логотипом на нужное место (по центру баннера, или повторяйте по сетке для пресс-волла)
5. Для максимального реализма добавьте слой-стиль логотипу:
   - Наложение цвета: подберите под освещение на рендере (обычно достаточно немного понизить яркость если баннер в тени)
   - Легкая тень: смещение 0, размер 5px, непрозрачность 15% чтобы логотип выглядел напечатанным, а не наклеенным

Готово! Получается идеальное фото с вашим точным оригинальным логотипом.
