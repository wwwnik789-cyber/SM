# Визуализации: брендирование офисов и зон ресепшн

Фотореалистичные 3D-рендеры для сайта, соцсетей, КП и презентаций нового направления **SM Production** — брендирование коммерческих интерьеров под ключ.

Фирменная палитра: тёмно-синий `#0F3460`, бирюза `#00ADB5`, белый `#FFFFFF`, тёмно-серый `#222831`.

## Как использовать

1. **Сайт** — галерея на странице `/uslugi/brendirovanie-ofisov` (когда услуга будет в каталоге).
2. **Соцсети** — карусели к постам из `smm/posts/new-direction-reception-offices.md`.
3. **КП** — 1–2 рендера рядом со сметой, чтобы клиент видел результат, а не только цифры.
4. **Замена логотипа** — рендеры с «SM» можно использовать как шаблон: в Photoshop заменить знак на логотип клиента.
