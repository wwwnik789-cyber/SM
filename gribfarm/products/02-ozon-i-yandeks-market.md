### Что важно для Директа
1. **Яндекс Маркет интегрирован с Директом нативно** — в типе кампании «Продажи на маркетплейсах» Маркет поддерживается **без API-ключей** (в отличие от OZON). Цель «Покупка» доступна и для Маркета, и для OZON (с интеграцией).
2. Плашка «Ниже рынка» на Маркете — бесплатный буст доверия; её стоит удерживать, не поднимая цену.
3. На Маркете у магазина всего 2.2K заказов и 301 подписчик против тысяч отзывов на OZON → **Маркет недогружен**. Есть потенциал роста без дополнительных затрат на трафик (буст продаж внутри Маркета дешевле внешнего трафика).

### ⚠️ Риск: нейминг карточки на Маркете
Название «…**для микродозинга и ноотропов**» содержит:
- **«ноотропы»** — отсылка к фармакологической группе препаратов → медицинское заявление, недопустимо для пищевого продукта;
- **«микродозинг»** — термин, прочно связанный с практикой микродозинга мухомора/психоактивных веществ; в модерации Яндекса это красный флаг.

Такое название **нельзя использовать в объявлениях Директа**. На самом Маркете оно может привести к запросу документов. Рекомендация — переименовать в нейтральное: «Мицелий ежовика гребенчатого GribFarm, 300 г, молотый, сушёный гриб».

### Что нужно получить от владельца для запуска OZON-кампании
1. Ссылка на магазин формата `https://www.ozon.ru/seller/<slug>/`.
2. **Performance API ключ**: OZON кабинет → Настройки → API-ключи → создать ключ Performance API → `Client ID` + `Client Secret`.
3. Префикс метки внешнего трафика: OZON кабинет → Аналитика → Внешний трафик → скопировать значение **`vendor_org_...`**.
4. Выгрузка SKU с ценами и остатками (чтобы не рекламировать out-of-stock).
5. Рейтинг контента карточек (OZON показывает оценку 0–100): рекламировать только карточки **≥70**.
