## 2. Яндекс Метрика

### 2.1 Счётчики
| Площадка | Счётчик | Статус |
|---|---|---|
| `gribfarm.ru` | ⚠️ проверить наличие | CMS Мегагрупп обычно ставит свой; нужен отдельный счётчик владельца |
| `gribfarmprices.tilda.ws` | ⚠️ проверить наличие | На бесплатном поддомене Tilda вставка кодов ограничена → ещё один аргумент за свой домен (P0 №2) |
| Промежуточные страницы Директа | Метрика Директа | создаётся автоматически при выборе соответствующей цели интеграции |

Действия:
- [ ] Установить/проверить счётчик на обоих сайтах.
- [ ] Включить **Вебвизор**, **карту скроллинга**, **карту кликов** — для прайса длиной в десятки экранов это основной инструмент диагностики.
- [ ] Включить «Разметка ссылок» не нужна (UTM ставим вручную), но включить **электронную коммерцию** (ecommerce) на прайсе — Tilda Store передаёт данные корзины.
- [ ] Связать Метрику с Директом (Директ → Настройки → Счётчики Метрики).
- [ ] Настроить **фильтр собственного трафика** (IP офиса в Мисайлово + IP агентства), иначе статистика будет засорена.

| C4 | `Клик по телефону` | JS-событие `tel:` | оба сайта | Звонки (коллтрекинг пока не подключаем) |
| C5 | `Клик по Telegram` | JS-событие `t.me` | оба сайта | Переход в мессенджер |
| C6 | `Клик по WhatsApp` | JS-событие `wa.me` | оба сайта | Переход в мессенджер |

**Композитная цель для стратегии:** `Покупка` (C1) → если данных мало, временно `Добавление в корзину` (C7) или `Отправка формы` (C3). Стратегия «Максимум конверсий» требует **не менее 10–20 конверсий в неделю** на кампанию, иначе не обучается. Если покупок меньше — ставим в цель микроконверсию и переходим на «Покупку» позже.

## 3. Атрибуция покупок на OZON

**Три вещи, без которых OZON-продажи не попадут в Директ:**

1. **Performance API ключ.** Кабинет продавца OZON → Настройки → API-ключи → Performance API → Создать ключ → перенести `Client ID` и `Client Secret` в кампанию Директа.
2. **Префикс `vendor_org_...`.** Кабинет OZON → Аналитика → Внешний трафик → скопировать и вставить в настройку интеграции Директа. Без префикса OZON не атрибутирует переход.
3. **Правильный тип цели интеграции** — «Максимум покупок с объявлений и статистика продаж в кабинетах Директа и Ozon». Тогда Директ сам скачивает отчёт по внешнему трафику по API и загружает покупки в цель «Покупка»; объявления ведут **напрямую в OZON**, без прокладки.

**Проверка после запуска (на 3–7 день):**
- [ ] В кабинете OZON → Аналитика → Внешний трафик появились переходы с пометкой Директа.
- [ ] В Директе в цели «Покупка» есть конверсии (могут отставать на 1–3 дня из-за переноса данных).
- [ ] Цифры OZON и Директа сходятся по порядку величин. Расхождение > 20% — проверить префикс `vendor_org`.

⚠️ Учитывать окно атрибуции: покупатель может добавить товар в корзину сегодня, а купить через 5 дней. Оцениваем кампанию не раньше чем через 7–14 дней.

## 4. Атрибуция Яндекс Маркета

- Интеграция в типе кампании «Продажи на маркетплейсах» для Маркета работает **без API-ключей**.
- Цель «Покупка» доступна сразу, оплата за покупки возможна.
- Параллельно в кабинете Маркета подключить «Буст продаж» — его статистику смотреть отдельно (Директ её не видит).
- ⚠️ Не запускать одновременно Директ-кампанию на Маркет и агрессивный буст продаж по тем же SKU — будет внутренняя конкуренция и рост CPC. Сначала развести по товарам, потом сводить.

## 5. UTM и разметка

### Шаблон
```
https://<посадочная>?
  utm_source=yandex-direct
  &utm_medium=cpc                     # cpc | cpa | display | social
  &utm_campaign=<NN_название>
  &utm_content=<группа>_<вариант>
  &utm_term=<ключ>                    # только для поиска
```

### Значения `utm_campaign`
| Код | Кампания |
|---|---|
| `01_ozon_marketplace` | Продажи на маркетплейсах — OZON |
| `02_yamarket_marketplace` | Продажи на маркетплейсах — Яндекс Маркет |
| `03_search_retail_<линия гриба>` | Поиск, розница |
| `04_search_b2b` | Поиск, опт/B2B |
| `05_rsy_retarget_<сегмент>` | РСЯ, ретаргетинг |
| `06_tg_channel_<группа>` | Telegram-канал |
| `07_brand` | Бренд |

### Правила
- Все ссылки внутри Telegram-канала, ВК, ОК, YouTube — **тоже с UTM**. Сейчас ссылки в канале (`gribfarmprices.tilda.ws/contacts`) размечены частично.
- Короткие ссылки OZON (`ozon.ru/t/...`) UTM не принимают → в рекламе использовать полные URL.
- Для Telegram-канала вести трафик **не напрямую** в `t.me`, а на прокладку со счётчиком: в Telegram нет Метрики, конверсию «подписка» иначе не измерить.

## 6. Сводная таблица контроля (вести еженедельно)

Завести файл `gribfarm/direct/reports/` и таблицу вида:

| Неделя | Кампания | Расход | Показы | Клики | CTR | CPC | Заказы | CPA | Выручка | **ДРР** | Решение |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 01_ozon | | | | | | | | | | |
| 1 | 02_yamarket | | | | | | | | | | |
| 1 | 07_brand | | | | | | | | | | |
| … | | | | | | | | | | | |

Плюс отдельные строки по:
- подписчикам Telegram (цена подписки),
- B2B-заявкам (цена лида, сколько дошло до КП, сколько до поставки),
- выручке по каналам: OZON / Маркет / Tilda / опт (⚠️ данные даёт владелец).

### Формулы
```
CTR      = клики / показы × 100%
CPC      = расход / клики
CR       = заказы / клики × 100%
CPA      = расход / заказы
ДРР      = расход на рекламу / выручка с рекламы × 100%
ROMI     = (прибыль − расход) / расход × 100%
Цена подписки = расход кампании 6 / прирост подписчиков
```

### Пороги для решений
| Ситуация | Действие |
|---|---|
| ДРР ≤ целевого 2 недели подряд | Масштабировать бюджет +20–30% |
| ДРР выше целевого, CPA растёт | Сначала чиним карточку/посадочную, потом ставки |
| CTR < 3% на поиске при 1 000+ показов | Переписать заголовок, проверить релевантность группы |
| CPC выше допустимого по юнит-экономике | Перейти на оплату за конверсию, сузить ключи |
| Конверсия карточки < 2% | Не масштабировать: фото, цена, отзывы, рейтинг контента |
| 0 конверсий при 50+ кликах | Проверить посадочную и цель, остановить группу |

### Расчёт предельной ставки за клик
```
CPA_max  = маржа с заказа × доля, которую готовы отдать на рекламу
CPC_max  = CPA_max × CR_карточки

Пример при марже 300 ₽, готовности отдать 40% маржи, CR 5%:
CPA_max = 300 × 0,4 = 120 ₽
CPC_max = 120 × 0,05 = 6 ₽      ← ниже рыночного CPC 25–70 ₽
```

**Вывод (повторяет `00-strategiya-zapuska.md`, п. 5):** при розничном чеке ~900 ₽ реклама в лоб по коммерческим ключам не окупается. Рабочие рычаги:
1. оплата **за покупки** (кампании 1, 2) — платим только за результат;
2. смещение трафика на **крупные фасовки и наборы** (чек 2 800–3 800 ₽);
3. **B2B-кампания** (чек в десятки тысяч, CPC окупается);
4. **LTV** через Telegram и марафон;
5. рост **органической позиции карточки** за счёт внешнего трафика — это отложенная, но бесплатная выручка.

## 8. Коллтрекинг и CRM — нужен ли

| Инструмент | Нужен? | Когда |
|---|---|---|
| Коллтрекинг | Позже | Только когда звонки станут значимым каналом. Сейчас телефон на сайте один, форм мало. Начать с цели C4 «клик по телефону» |
| CRM (amoCRM/Битрикс24) | **Да, для B2B** | Кампания 4 генерирует заявки с длинным циклом сделки (опт от 10 кг, white label). Без CRM лиды теряются. Минимум — таблица с этапами |
| Сквозная аналитика (Roistat/Calltouch) | Позже | Когда бюджет превысит ~150–200 тыс ₽/мес и появится 3+ канала с разной атрибуцией |
| Telegram-бот как CRM | Уже есть | `@marafongribfarmbot` — использовать для учёта участников марафона и повторных покупок |
