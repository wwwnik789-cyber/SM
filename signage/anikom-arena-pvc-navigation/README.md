# Брендированные навигационные ПВХ-таблички «Аником Арена»

Единая система из 20 табличек в фирменных цветах арены. Все надписи переведены в векторные контуры; подключаемые шрифты и растровые изображения в готовых SVG не используются.

## Главный файл

- [`anikom-arena-navigation-master-sheet.svg`](./anikom-arena-navigation-master-sheet.svg) — один мастер-лист со всеми табличками и отдельным слоем контуров реза;
- [`master-sheet-preview.png`](./master-sheet-preview.png) — превью всего комплекта;
- [`individual/`](./individual/) — каждая табличка отдельным SVG;
- [`sign-register.csv`](./sign-register.csv) — реестр названий и файлов.

## Размеры и производство

- чистовой размер каждой таблички: **600 × 200 мм**;
- пропорция: **3:1**;
- вылеты: **3 мм** с каждой стороны;
- размер индивидуального SVG с вылетами: **606 × 206 мм**;
- мастер-лист: **2524 × 1150 мм**;
- углы контура реза: радиус **12 мм**;
- слой печати: `PRINT`;
- слой реза: `CUT_CONTOUR`;
- каждый контур реза — отдельный замкнутый path с идентификатором `CUT__...`;
- цвет линии реза в SVG: `#FF00FF`, толщина `0,5 мм`.

Перед производством линию `#FF00FF` следует назначить как служебный spot-color `CutContour` в программе, используемой конкретным производством, и отключить её печать. Если табличку масштабируют, печатный макет и контур реза нужно масштабировать вместе.

## Техническая проверка

- 20 отдельных замкнутых контуров реза на мастер-листе;
- по одному контуру реза в каждом индивидуальном SVG;
- элементов `<text>` нет;
- шрифтовых зависимостей нет;
- ссылочных элементов `<use>` нет — символы полностью развёрнуты в кривые;
- все пиктограммы и логотип — векторные;
- фон продолжается на всю область вылетов.

## Пересборка

```bash
python -m venv .venv
.venv/bin/pip install -r signage/anikom-arena-pvc-navigation/requirements.txt
.venv/bin/python signage/anikom-arena-pvc-navigation/build_signs.py
```

Исходный Montserrat Variable и его лицензия OFL сохранены в `source/` только для воспроизводимой пересборки. В готовых SVG шрифт не подключается.
