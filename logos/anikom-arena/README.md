# Векторный логотип ANIKOM ARENA

Готовые файлы содержат **настоящие векторные контуры**: внутри SVG нет PNG/JPEG, шрифтов и редактируемого текста. Белая графика сохранена на прозрачном фоне без изменения пропорций и композиции исходника.

## Файлы

- [`anikom-arena-logo-vector.svg`](./anikom-arena-logo-vector.svg) — основной рабочий SVG, холст плотно обрезан по прозрачным полям; рекомендуемый файл для макетов и печати.
- [`anikom-arena-logo-vector-original-canvas.svg`](./anikom-arena-logo-vector-original-canvas.svg) — тот же вектор на исходном холсте `880 × 1184`, включая оригинальные прозрачные поля.
- [`preview-black-background.png`](./preview-black-background.png) — контрольный просмотр белого логотипа на чёрном фоне; фон входит только в превью, не в SVG.
- [`qa-report.txt`](./qa-report.txt) — результаты автоматической проверки.
- [`source/anikom-arena-logo.png`](./source/anikom-arena-logo.png) — исходный PNG для воспроизводимой сборки.

## Технические параметры

- основной SVG: `836 × 823`, `viewBox="25 174 836 823"`;
- исходный холст: `880 × 1184`, `viewBox="0 0 880 1184"`;
- 61 замкнутый векторный контур;
- цвет графики: `#FFFFFF`;
- фон: прозрачный;
- текст переведён в кривые, внешние шрифты не требуются;
- масштабирование выполняется без потери качества.

Обрезка прозрачных полей в основном файле не изменяет сам логотип: геометрия контуров совпадает с версией на исходном холсте.

## Воспроизводимая сборка

```bash
python -m venv .venv
.venv/bin/pip install -r logos/anikom-arena/requirements.txt
.venv/bin/python logos/anikom-arena/build.py
```
