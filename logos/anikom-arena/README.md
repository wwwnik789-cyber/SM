# Векторный логотип ANIKOM ARENA

Логотип восстановлен как **чистая векторная композиция**, а не как грубая попиксельная автотрассировка. Буквы заново построены по контурам Montserrat и переведены в кривые; четыре фирменных скобочных знака обработаны отдельно с четырёхкратной дискретизацией. В главном слове «АРЕНА» всем пяти буквам задана единая высота, насыщенность и угол — узкая «Е» больше не масштабируется отдельно по площади.

В SVG нет PNG/JPEG, живого текста, подключаемых шрифтов, масок и фонового прямоугольника. Белая графика находится на прозрачном фоне.

## Готовые файлы

- [`anikom-arena-logo-vector.svg`](./anikom-arena-logo-vector.svg) — основной рабочий SVG, холст обрезан только по исходным прозрачным полям.
- [`anikom-arena-logo-vector-original-canvas.svg`](./anikom-arena-logo-vector-original-canvas.svg) — тот же вектор на исходном холсте `880 × 1184`.
- [`preview-black-background.png`](./preview-black-background.png) — контрольный просмотр на чёрном фоне; чёрный фон присутствует только в превью.
- [`qa-report.txt`](./qa-report.txt) — результаты автоматической проверки геометрии и состава SVG.
- [`source/anikom-arena-logo.png`](./source/anikom-arena-logo.png) — исходный PNG.

## Технические параметры

- основной SVG: `836 × 823`, `viewBox="25 174 836 823"`;
- версия с исходным холстом: `880 × 1184`, `viewBox="0 0 880 1184"`;
- 61 отдельный векторный объект, как в исходной композиции;
- среднее отклонение центров объектов от PNG: `0,624 px`;
- максимальное отклонение центров объектов: `0,824 px`;
- высота всех букв главного слова в направлении строки: `146,06–146,12 px`;
- цвет графики: `#FFFFFF`;
- фон: прозрачный;
- масштабирование: без потери качества.

## Воспроизводимая сборка

Используемый для восстановления Montserrat Variable приложен в `source/` вместе с лицензией OFL. В готовом SVG шрифт не подключается — все символы уже переведены в кривые.

```bash
python -m venv .venv
.venv/bin/pip install -r logos/anikom-arena/requirements.txt
.venv/bin/python logos/anikom-arena/build.py
```
