# Пост «Маленькие детали для Вашего бизнеса»

## Готовые материалы

- `post.md` — текст публикации, хештеги и редакционное примечание;
- `01-fotoprops-pizza-croissant-coffee.jpg` — фотопропсы в живой сцене кафе;
- `02-navigation-signs.jpg` — смонтированные интерьерные указатели;
- `03-prize-wheel-cafe.jpg` — физическое колесо фортуны в работе;
- `04-fictional-character-standee.jpg` — ростовая фигура оригинального фирменного персонажа.

Все финальные изображения подготовлены в горизонтальном формате 1200×675. Вторая версия выполнена как смешанная серия: предмет показан крупно, но остаётся частью естественной сцены с посетителями.

`build_visuals.py` собирает финальные файлы из исходных сцен и добавляет точные русские надписи на физические указатели и сектора колеса фортуны.
