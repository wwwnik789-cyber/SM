# Пост «Маленькие детали для Вашего бизнеса»

## Готовые материалы

- `post.md` — текст публикации, хештеги и редакционное примечание;
- `01-fotoprops-pizza-croissant-coffee.jpg` — фотопропсы;
- `02-navigation-signs.jpg` — интерьерные указатели;
- `03-prize-wheel-cafe.jpg` — колесо фортуны;
- `04-edward-cullen-standee.jpg` — ростовая фигура в кафе.

Все финальные изображения подготовлены в горизонтальном формате 1200×675.

`build_visuals.py` собирает финальные файлы из исходных сцен и добавляет точные русские надписи на навигацию и колесо фортуны.

Визуал с Эдвардом Калленом — концепция. Для коммерческого производства необходимо использовать изображение, права на которое подтверждены заказчиком или правообладателем.
