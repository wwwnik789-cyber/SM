# Баннер для телебашни «Аником Арена»

Квадратный макет в фирменных цветах арены: крупный основной логотип расположен в центре, по фону собрана мелкая повторяющаяся сетка в стиле пресс-волла.

## Готовые файлы

- `anikom-arena-tv-tower-banner-4000x4000.svg` — основной полностью векторный макет для производства;
- `preview-1200x1200.png` — уменьшенное изображение для согласования.

## Параметры

- конечный размер: **4000 × 4000 мм**;
- масштаб макета: **1:1**;
- фон: тёмно-синий с красными фирменными акцентами;
- основной логотип: 1820 × 1790 мм, по центру;
- сетка: 7 × 7 малых логотипов;
- растровых изображений в SVG нет;
- шрифты не используются: логотип переведён в векторные контуры;
- группы SVG подписаны: `ФОН`, `МЕЛКАЯ СЕТКА`, `ЦЕНТРАЛЬНОЕ ПОЛЕ`, `ОСНОВНОЙ ЛОГОТИП`.

Перед печатью производству необходимо проверить требования к вылетам и способу сборки полотна. Если нужны вылеты, их следует добавить сверх конечного размера 4000 × 4000 мм по требованиям конкретного производства.

## Пересборка

```bash
python3 -m venv .venv
.venv/bin/pip install -r banners/anikom-arena-tv-tower/requirements.txt
.venv/bin/python banners/anikom-arena-tv-tower/build_banner.py
```
