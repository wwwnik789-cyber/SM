# Горизонтальные баннеры для нижней части трибуны

Два баннера размещаются **только на нижних участках фасада**, которые пользователь отметил красными прямоугольниками на фотографии:

- левый участок под левой трибуной;
- правый участок под правой трибуной.

Балконная линия, центральный вход и верхнее ограждение в эту задачу не входят.

## Макеты

Оба баннера оформлены одинаково:

- крупный основной логотип в центре;
- мелкая повторяющаяся сетка в стиле пресс-волла;
- тёмно-синий фон;
- красные фирменные акценты;
- все элементы переведены в векторные контуры.

## Предварительные размеры

Размеры выбраны по пропорциям красных прямоугольников на фотографии:

- левый: `2800 × 1000 мм`, пропорция 2,8:1;
- правый: `4000 × 1000 мм`, пропорция 4:1.

Это **предварительные размеры**. Перед печатью нужно измерить ширину и высоту обеих поверхностей. SVG можно масштабировать без потери качества.

## Готовые файлы

- `anikom-arena-lower-left-2800x1000.svg` — левый векторный макет;
- `anikom-arena-lower-right-4000x1000.svg` — правый векторный макет;
- файлы `.svgz` — те же макеты в сжатом векторном формате для прямого скачивания с GitHub;
- `placement-preview.jpg` — оба баннера на отмеченных местах фотографии;
- `banners-preview-1600x1100.jpg` — чистый лист с двумя макетами;
- `preview-left-1400x500.png` и `preview-right-1600x400.png` — отдельные просмотровые изображения.

В SVG нет растровых изображений и шрифтов. Группы подписаны: `ФОН`, `МЕЛКАЯ СЕТКА`, `ЦЕНТРАЛЬНОЕ ПОЛЕ`, `ОСНОВНОЙ ЛОГОТИП`.

## Пересборка

```bash
python3 -m venv .venv
.venv/bin/pip install -r banners/anikom-arena-lower-facade/requirements.txt
.venv/bin/python banners/anikom-arena-lower-facade/build_banners.py
```
