# Печатные мастера «Кастинг-лист» — вторая концепция серии

Принципиально другой визуальный язык для той же конструкции 300 × 270 см
и тех же трёх макетов. Вместо сценического маджента с золотом — редакционная
«бумага»: тёплый off-white, глубокий сине-чёрный, вермильоновый акцент.

Всё в sRGB, 300 dpi, 4:4:4, без вылетов — печать строго в размер.
Файлы собраны в **Q78**: полотно «бумажных» макетов сжимается лучше
сценических, вес укладывается в лимит GitHub (100 МБ на файл).

Палитра: бумага `#F3EEE4`, чернила `#141729`, акцент `#E23A20`,
второстепенный `#7C7972`. Дуотон фотографий: тени `#151A2E` → света
`#F6F0E2` — так три разных исходника читаются как один ряд.

**Безопасная зона.** Весь текст лежит в полосе 40…180 см: уши — зеркало
крайних 40 см лица, и надписи в них читались бы задом наперёд.
Фотополоса и линейки под фото, наоборот, идут во всю ширину — они фоновые.

## Сборка

```bash
python3 scripts/banners/build_300x270.py --style sheet --quality 78
python3 scripts/banners/build_300x270.py --style sheet --bare --quality 78
```

**QR-код вставляет клиент** — в мастере остаётся зона 21 × 21 см.
Если нужен вариант с готовым кодом (собственный QR, `https://model.dvkino.ru`),
добавьте флаг `--with-qr`:

```bash
python3 scripts/banners/build_300x270.py --style sheet --with-qr
```

Максимальное качество — `--quality 92` (файлы больше 100 МБ, в git не
кладутся, отдавать типографии из рабочей папки).

Превью и видимые лица:

```bash
python3 scripts/banners/make_preview_300x270.py --style sheet
```

## CMYK (FOGRA39)

По решению клиента собраны CMYK-версии всех шести мастеров обеих
концепций — TIFF 8 бит/канал, профиль `Coated FOGRA39 (L) VIGC 300`
(X-Rite / ECI) встроен в файл, рендеринг относительный с компенсацией
чёрной точки:

```bash
python3 scripts/banners/to_cmyk.py --profile scripts/banners/icc/Coated_Fogra39L_VIGC_300.icc
```

Файлы крупные (114 МБ – 1,1 ГБ), в git не кладутся — отдаются типографии
с рабочего диска. В репозитории лежат оба профиля:
`scripts/banners/icc/Coated_Fogra39L_VIGC_300.icc` (X-Rite/ECI) и
`scripts/banners/icc/craft-coated-fogra39.icc` (CC0, FOGRA39 по данным Fogra).

## Проверка

```bash
python3 scripts/banners/qa_300x270.py
```

300 dpi, 4:4:4 и декодирует QR прямо из печатного файла
(`https://model.dvkino.ru`).
