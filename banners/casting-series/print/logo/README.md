# Логотип «ДВ PRODUCTION» — отдельный слой

Клиент прислал логотип двумя файлами по 500 × 500 (`logo.jpg` и
`logo копия.png`): монограмма обрезана по верхнему и нижнему краю, фон
залит маджентой, в «копии» — белый блок внутри «Д». Ставить такой логотип
на баннер нельзя.

Здесь — пересобранный логотип: **векторный SVG** и **печатный PNG с
прозрачностью**, которые кладутся на баннер отдельным слоем.

| Файл | Размер | Формат | Назначение |
|------|--------|--------|------------|
| `logo-dv-production.svg` | 320 × 307 мм, viewBox 3718 × 3570 | SVG (2 пути, evenodd) | вектор: Illustrator, Figma, Photoshop, InDesign — можно менять цвет и масштаб без потерь |
| `logo-dv-production-32cm-300dpi.png` | 3780 × 3630 px (32 × 30,7 см) | PNG RGBA, sRGB, 300 dpi | растровый слой с прозрачностью для печати и вёрстки |
| `logo-dv-production-preview-magenta.jpg` | 1400 px | JPEG | превью на фирменном мадженте #971a81 |
| `logo-dv-production-preview-dark.jpg` | 1400 px | JPEG | превью на тёмном фоне |

CMYK-версия с профилем FOGRA39 и альфа-каналом (9 МБ) — в
[`../cmyk/`](../cmyk) (в git не кладётся, отдаётся типографии с рабочего
диска).

## Как собрано

Скрипт — [`scripts/banners/logo_vector.py`](../../../scripts/banners/logo_vector.py).

1. **Форма взята из полного исходника** 6144 × 6144
   (`banner-dv-production-original-6144x6144.jpg`): монограмма 1944 × 1431,
   надпись «PRODUCTION» 1830 × 317. Клиентский файл обрезан, поэтому как
   источник формы он не годится.
2. **Маты по тону.** Золото отделяется от мадженты по тону (20…60°) с
   мягким порогом по насыщенности: пересвеченные лучом участки золота
   остаются в мате — иначе на верхнем стволе монограммы появляется вырез.
   Светлая надпись отделяется по яркости и бесцветности.
3. **Уборка.** Случайные компоненты (< 800 px) удаляются, мелкие дыры от
   бликов закрываются, счётные зоны («Д», «О», «Р») сохраняются.
4. **Трассировка.** Контуры → Douglas–Peucker → передискретизация по длине
   дуги → гауссово сглаживание по кругу (σ 2,2 px для монограммы, 2,0 px
   для надписи) → сглаживание Чакина. На выходе — настоящие векторные
   пути, ровные дуги без «дрожи» края.
5. **Сборка.** Градиент золота клиента: #FCE9A1 → #F0D994 → #CC9C34 →
   #A76F20; надпись — тёплый белый #FCF1D4. Ширина надписи = ширина
   монограммы, зазор — 21,5 % высоты монограммы (пропорции клиента).
   Поля по периметру — 2 %.

## Пересборка

```bash
python3 scripts/banners/logo_vector.py --profile original --out-dir banners/casting-series/print/logo
python3 scripts/banners/logo_vector.py --profile original --width-cm 20 --out-dir /tmp/logo20
```

`--profile original` — полный исходник 6144² (форма клиента);
`--profile client` — плоский файл клиента (обрезан, только для сравнения).
`--width-cm` меняет физический размер мастера (по умолчанию 32 см — как
лого-блок на баннере).
