### Где скачать

Мастера конструкции **не хранятся в git**: GitHub не принимает файлы
больше 100 МБ, а эти весят 92–141 МБ. Они выложены в релизе репозитория:

**https://github.com/wwwnik789-cyber/SM/releases/tag/banners-300x270**

Там же лежат превью (1600 px) для быстрого просмотра и все производные
версии для сайта и соцсетей.

Пересобрать локально из исходников — одна команда:

```bash
python3 scripts/banners/build_300x270.py          # с подписями и QR
python3 scripts/banners/build_300x270.py --bare   # чистые, без подписей и QR
python3 scripts/banners/qa_300x270.py             # проверка: геометрия, dpi, 4:4:4, QR
```

Схема раскладки конструкции — `../preview/casting-300x270-layout.jpg`,
итоговый вид серии — `../preview/casting-300x270-contact-sheet.jpg`
и `../preview/casting-300x270-bare-contact-sheet.jpg`.
