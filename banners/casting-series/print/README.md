## Вторая концепция — «Кастинг-лист» (`sheet/`)

Та же конструкция 300 × 270 см и те же три макета, но принципиально другой
визуальный язык: редакционная «бумага» вместо сценического маджента.
Мастера лежат в подпапке `sheet/`, описание композиции — в
[`sheet/README.md`](sheet/README.md).

```bash
python3 scripts/banners/build_300x270.py --style sheet --quality 78
python3 scripts/banners/build_300x270.py --style sheet --bare --quality 78
```

## Сцена — отдельный мастер (`stage/`)

Кадр сцены, обработанный под печать: чистка, грейд к фирменному мадженте
#971a81 и апскейл до 220 см при 300 dpi. Композиция исходника не менялась.
Описание пайплайна — в [`stage/README.md`](stage/README.md).

```bash
python3 scripts/banners/print_stage.py --src <кадр.png> --out-dir banners/casting-series/print/stage --width-cm 220
```

## Логотип клиента — отдельный слой (`logo/`)

Клиентский логотип пересобран в вектор: **монограмма «Д» отдельным
слоем** и полный локап (монограмма + надпись PRODUCTION) — SVG + печатные
PNG с прозрачностью (32 см, 300 dpi) и CMYK-версии с профилем FOGRA39.
Форма взята из полного исходника 6144 × 6144 — присланный клиентом файл
500 × 500 обрезан. Контуры — подогнанные кубические кривые Безье: ровные
дуги, острые углы как в оригинале. Подробности — в
[`logo/README.md`](logo/README.md).

```bash
python3 scripts/banners/logo_mark.py --out-dir banners/casting-series/print/logo
```

### Про качество и вес
Полотно 300 × 270 см — это 1,13 гигапикселя, и в JPEG Q92 файл весит
92–141 МБ. GitHub не принимает в git файлы больше 100 МБ, поэтому мастера
собраны в **Q78**: средняя разница с Q92 по пикселям — 0,5/255, максимум
9/255, на гладком маджентовом градиенте полос не появляется. Для печати
трёхметрового баннера это неразличимо; на вид разница тем меньше, чем
дальше смотреть.

Максимальное качество пересобирается одной командой (файлы получатся
больше 100 МБ — их нужно отдавать типографии из рабочей папки или
залить в релиз GitHub вручную):

```bash
python3 scripts/banners/build_300x270.py --quality 92
python3 scripts/banners/build_300x270.py --bare --quality 92
```

### Проверка

```bash
python3 scripts/banners/qa_300x270.py
```

Скрипт проверяет геометрию (35 433 × 31 890 px = 300 × 270 см при
300 dpi), плотность 300 dpi в сегменте JFIF, отсутствие chroma-subsampling
(4:4:4) и декодирует QR прямо из печатного файла. В чистых макетах
(`-bare`) QR не декодируется — так и задумано.
