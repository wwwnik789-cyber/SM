# Сцена — отдельный печатный мастер (300 dpi)

Обработка клиентского кадра сцены (`1792567453.png`, 1664 × 928 px) под печать
баннера. **Композиция не менялась**: тот же кадр, тот же кроп, ничего не
перерисовывалось — только чистка, грейд к фирменному мадженте и печатный
апскейл до 300 dpi.

| Файл | Размер | Формат | Назначение |
|------|--------|--------|------------|
| `stage-print-xl-300dpi.jpg` | 25 984 × 14 491 px (220 × 123 см) | JPEG Q95, sRGB, 4:4:4, 300 dpi | печатный мастер |
| `stage-print-xl-preview.jpg` | 1600 × 892 px | JPEG Q88 | превью для согласования и сайта |

CMYK-версия (491 МБ) — в [`../cmyk/`](../cmyk) (в git не кладётся, отдаётся
типографии с рабочего диска).

## Что сделано

Скрипт — [`scripts/banners/print_stage.py`](../../../scripts/banners/print_stage.py).

1. **Чистка.** Хроматическое шумоподавление (CbCr, гаусс σ 2,5) + мягкая
   фильтрация по яркости (bilateral): «карамельный» шум исходника убран, но
   звёзды, лучи и вертикальные линии остались резкими.
2. **Грейд к #971a81.** Lab-тяга `a/b` к фирменному мадженте (k = 0,55) по
   маджента-семейству (H 268…348°), золото лучей и красный ковёр защищены
   маской по тону; +15 % насыщенности в мадженте и лёгкий split-tone в тенях.
   Итог: маджента-семейство **H 325° → 316°, S 55 % → 82 %** (цель #971a81 =
   H 311°, S 83 %), светлота не тронута — тоновая структура кадра сохранилась.
3. **Печатный апскейл ×15,6.** LANCZOS полосами (memmap, RSS < 1,4 ГБ) плюс
   отдельный слой деталей — микро-контраст не замыливается; unsharp mask
   (r = 4 px, 62 %) и плёночное зерно σ 1,05/255 как дизер против бандинга
   на больших площадях.
4. **Вывод.** JPEG 4:4:4 Q95, 300 dpi (sRGB) + TIFF CMYK 8 бит с встроенным
   ICC `Coated FOGRA39 (L) 300 % TAC`, intent relative, BPC.
   Раунд-трип sRGB → CMYK → sRGB: среднее отклонение **1,5/255**, p99 — 11/255.

## Пересборка

```bash
python3 scripts/banners/print_stage.py \
  --src /tmp/arena-coding-uploads/1792567453.png \
  --out-dir banners/casting-series/print/stage \
  --width-cm 220
```

Параметры грейда: `--hue-pull` (сила Lab-тяги 0…1), `--sat-boost`,
`--tint` (split-tone в тенях), `--target` (HEX целевого цвета).
Полный прогон на 220 см — около 70 с, CMYK добавляет ещё ~2 мин.
