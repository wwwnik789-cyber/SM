# Концепции баннеров 3000 × 2500 мм для «Аником Арены»

Четыре полностью векторных направления для стандартных плоских баннерных конструкций. Все макеты подготовлены в масштабе 1:1, используют исправленный векторный логотип арены и не содержат растра, живого текста, подключаемых шрифтов или ссылочных SVG-символов.

## Концепции

### 1. Arena Core

- [`01-arena-core.svg`](./01-arena-core.svg)
- [`preview`](./previews/01-arena-core.png)

Крупный круговой логотип, спокойная симметричная композиция и минимум дополнительного текста. Универсальный имиджевый вариант для постоянного размещения.

### 2. Match Day

- [`02-match-day.svg`](./02-match-day.svg)
- [`preview`](./previews/02-match-day.png)

Активная композиция для матчей и трансляций: место под дату и время, три партнёрских блока и фоновая схема футбольного поля. Перед печатью информационные заглушки заменяются на реальные данные.

### 3. Arena Energy

- [`03-arena-energy.svg`](./03-arena-energy.svg)
- [`preview`](./previews/03-arena-energy.png)

Самый динамичный вариант: крупная фоновая типографика, диагональные полосы и спортивная графика. Подходит для событийных площадок и заметных точек на поле.

### 4. Partner Photozone

- [`04-partner-photozone.svg`](./04-partner-photozone.svg)
- [`preview`](./previews/04-partner-photozone.png)

Бренд-паттерн для фотографирования и партнёрских интеграций. Ячейки `ПАРТНЕР` предназначены для замены на реальные логотипы спонсоров.

Общее превью всех направлений: [`concepts-overview.png`](./concepts-overview.png).

## Производственные параметры

- чистовой размер: **3000 × 2500 мм**;
- масштаб: **1:1**;
- безопасная зона для значимых элементов: **120 мм** от края;
- основной фон продолжается до края полотна;
- все надписи переведены в кривые;
- логотип и графика полностью векторные;
- элементов `<text>`, `<image>` и `<use>` нет;
- цветовая модель SVG — RGB; перевод в CMYK выполняется по профилю конкретного производства.

Припуски на карманы, загиб, сварку или конкретную систему натяжения не добавлены, поскольку они зависят от конструкции. Производству следует добавить их сверх чистового размера по своей технологической карте.

## Фирменные цвета

- тёмно-синий: `#081A2B`;
- дополнительный синий: `#102A44`;
- тёмный сливовый: `#2C222E`;
- коралловый: `#D94A43`;
- белый: `#FFFFFF`.

## Пересборка

```bash
python -m venv .venv
.venv/bin/pip install -r banners/anikom-arena-3000x2500-concepts/requirements.txt
.venv/bin/python banners/anikom-arena-3000x2500-concepts/build_concepts.py
```

Montserrat Variable и его лицензия OFL сохранены в `source/` только для воспроизводимой пересборки. Готовые SVG от шрифта не зависят.
