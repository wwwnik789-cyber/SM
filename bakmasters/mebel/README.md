# Комбинированная мебель для дома — пакет BAK HOME

Направление HOME: столешницы из дуба, смолы и природного камня на металлокаркасе с порошковой
покраской. 12 позиций, 4 группы.

## Что в пакете

Исходники текста — `.md` в этой же папке (для истории и пересборки).

## Три вещи, без которых пакет не работает

**1. Цены.** Все вилки в файлах — ориентиры по Москве ⚠️. Их надо подтвердить: в разделе 10
файла `PDF-1` есть 16 вопросов, первый — реальные цифры по строкам формулы.

**2. Покраска.** Это единственный этап, который не под нашим контролем. Нужен второй подрядчик,
иначе сроки будут ехать на каждой второй позиции.

**3. Прототип 4.1.** Столик для ноутбука с вентиляторами — то, чего нет у конкурентов в дереве.
Его надо сделать первым и измерить: температура, шум, вибрация, опрокидывание.

## Порядок запуска

1. Подтвердить цены и покраску.
2. Собрать прототип 4.1, замерить по чек-листу из `PDF-2`, раздел 7.
3. Снять 3 позиции в реальном интерьере (обеденный, прикроватная, столик для ноутбука).
4. Собрать раздел на Tilda по текстам из `PDF-3`.
5. Завести карточки в Store, связать с `/sotrudnichestvo`.
6. Дать дизайнерам первой — у них уже есть вход на объекты.
