# SEO страниц BAK MASTERS

Готовые тексты: скопировать и вставить в поля Тильды. Ниже — таблица для сверки
и блоки для копирования.

## Правила, по которым это написано

| Поле | Длина | Что писать |
|---|---|---|
| **Title** | 50–65 знаков | Главный запрос в начале, бренд в конце. У каждой страницы свой |
| **Description** | 140–160 знаков | Что на странице + выгода + мягкий призыв. Влияет не на позиции, а на клики |
| **H1** | 30–60 знаков | Один на страницу. По смыслу совпадает с Title, но не слово в слово |
| **Alt** | 60–90 знаков | Описание того, что на фото. Отдельный документ |

**Ключевые запросы проекта:** изделия из дерева и эпоксидной смолы, столы из
с массива дерева, чабань, кухонная доска (борд), подсвечник из дерева, подарок
ручной работы, мебель на заказ. Брендовые: BAK MASTERS, бак мастерс.

Тильда не любит длинные Title: в выдаче Яндекса видно примерно 50–55 знаков,
остальное обрезается многоточием. Поэтому бренд ставим в конец — если обрежется,
потеряем меньше.

## Товары: формула и примеры

В магазине 37 карточек. У каждой сейчас Title — либо просто название
(«МАЙГОТО абрикос»), либо тип без имени («BAK MASTERS Подсвечник», и таких
несколько — они дублируются между собой). Правим по формуле:

```
{Тип} {НАЗВАНИЕ} из {материал} — BAK MASTERS
```

**Description для товара:**

```
{Что это и из чего}. Размер {Д × Ш × В} мм. {Для чего / кому дарят}. Ручная работа, доставка по России.
```

## Чего не делать с Title

- Не ставить одно и то же на разные страницы: сейчас у нескольких товаров Title
  «BAK MASTERS Подсвечник» — Яндекс считает такие страницы дублями.
- Не писать «Купить в Москве недорого» — это не запрос для изделий ручной работы.
- Не добавлять год и цены в Title: через месяц устареет.
