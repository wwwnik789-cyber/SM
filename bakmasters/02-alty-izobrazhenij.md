# Альты изображений BAK MASTERS

Альты уже прописаны на главной — база хорошая. Этот документ нужен, чтобы:
выровнять их по одному правилу, закрыть страницы, где их нет, и не скатиться
в перечисление ключевых слов.

## Правило

Альт отвечает на вопрос «что на этом фото». Не «что мы продаём», а «что видно».

**Формула:** `тип изделия + материал + техника (+ место или назначение)`

Хорошо: `кухонная борда из массива дерева с заливкой эпоксидной смолой`
Плохо: `доска купить подарок дерево смола ручная работа москва`
Плохо: `DSC_9849.JPG`

| Правило | Почему |
|---|---|
| 60–90 знаков | Короче — мало смысла, длиннее — не читают и не учитывают целиком |
| Своё описание у каждого фото | Одинаковые альты на странице выглядят как спам |
| Без слов «фото», «картинка», «image» | Скринридер и так знает, что это изображение |
| Без перечисления запросов через запятую | Это видно за километр и не помогает ранжированию |
| У декоративных картинок и заглушек — пусто | Заглушка `photo.png` не описывается: её сначала надо заменить |
| Бренд — максимум в 1–2 альтах на страницу | В остальных он не нужен |

## Карточка товара

Пять ракурсов — пять разных альтов. Это самый важный раздел: карточки дают
трафик по запросам вида «подсвечник из дерева купить».

| Слот | Alt |
|---|---|
| 1. Главное фото | `подсвечник {НАЗВАНИЕ} из массива {порода} с эпоксидной смолой` |
| 2. Столешница / лицевая часть крупно | `рисунок спила {порода} под заливкой эпоксидной смолы крупным планом` |
| 3. Торец или боковая часть | `обработанный торец изделия из {порода}, пропитан маслом` |
| 4. В интерьере | `{тип изделия} в интерьере: {стол / полка / подоконник}` |
| 5. Упаковка | `подарочная упаковка изделия BAK MASTERS перед отправкой` |
| 6. Свеча / рюмки / декор в работе | `{тип изделия} с {свечой / рюмками} в использовании` |

**Пример для ТИВДИИ:**

1. `подсвечник ТИВДИЯ из массива ореха с молочно-бежевой заливкой`
2. `рисунок массива ореха под заливкой эпоксидной смолы крупным планом`
3. `обработанный торец подсвечника, пропитан маслом и воском`
4. `подсвечник ТИВДИЯ с горящей свечой на столе в интерьере`
5. `подарочная упаковка подсвечника BAK MASTERS`

**Пример для борда ПУТОРАНО:**

1. `кухонный борд ПУТОРАНО НУАР из массива дерева с эпоксидной смолой`
2. `рисунок дерева на разделочной доске крупным планом`
3. `торец борда, пропитанный пищевым маслом`
4. `борд с нарезкой на кухонном столе`
5. `подарочная упаковка борда перед отправкой`

## Как проверить уже прописанное

Пять минут по каждой странице:

- [ ] Нет двух одинаковых альтов на одной странице.
- [ ] Ни в одном альте нет слов «фото», «картинка», «изображение».
- [ ] Все альты короче 100 знаков.
- [ ] В альте есть тип изделия и материал — это главное.
- [ ] У заглушек и декоративных линий alt пустой.
- [ ] Названия файлов при загрузке переименованы: `podstavka-dlya-blagovonij-santala.jpg`
      вместо `DSC_9554.jpg`. На ранжирование это почти не влияет, но в поиске
      по картинкам работает.
