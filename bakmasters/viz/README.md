# Пакет для сборки страницы «Сотрудничество» в Tilda

Всё, что нужно, чтобы собрать страницу руками — без доступа к вашему проекту.
Скачайте PDF из этой папки и работайте по порядку.

---

## Что в пакете

| Файл | Зачем |
|---|---|
| `PDF-1-tekst-pod-kopirovanie.pdf` | **главный файл.** Текст всех 13 блоков, настройки страницы, цвета, шрифты, вопросы владельцу — 11 страниц |
| `PDF-2-instrukciya-po-sborke.pdf` | эта инструкция в PDF |
| `PDF-3-maket-stranicy.pdf` | макет по блокам: обзор страницы целиком + 13 страниц крупно, с подписью «БЛОК N · элемент Tilda» |
| `DOCX-1-tekst-pod-kopirovanie.docx` | тот же текст в Word — если нужно что-то поправить самому |
| `DOCX-2-instrukciya-po-sborke.docx` | инструкция в Word |

Начинать с `PDF-1` и `PDF-3`: в первом — что вставлять, во втором — как это должно выглядеть.

**Архив со всем сразу:** `SM-BAKMASTERS-sotrudnichestvo.zip` (в папке `docs/`).

## Порядок сборки — 40 минут

**1. Создать страницу (2 мин)**
«Страницы» → «Создать» → пустая. URL: `sotrudnichestvo`.
Вкладка **SEO**: вставить Title и Description из `PDF-1` (самый верх файла).

**2. Собрать блоки (30 мин)**
Идёте по `PDF-1` сверху вниз. Перед каждым блоком написано: `Элемент Tilda: T-cards — сетка 3 × 2`.
Смотрите в `PDF-3` (или в `MAKET-stranicy.jpg`), как блок должен выглядеть, и повторяете у себя тем же элементом.
Тексты копируете из файла — они уже финальные, ничего дописывать не нужно.

**3. Настроить цвета и шрифты (5 мин)**
Палитра и размеры — в разделе «Настройки оформления» в конце `PDF-1`.
Проще всего: «Настройки сайта» → «Цвета» → поставить фон страницы `#F6F1E9`, акцент `#2F6F6B`.

**4. Форма (3 мин)**
`T-form`: включить загрузку файлов, поставить чекбокс согласия со ссылкой на `/privacypolicy`,
добавить копию заявки на `bak.masters@yandex.ru`. Отправить тестовую заявку.

## Три вещи, без которых страница не заработает

**1. Цифра партнёрской скидки.** Блок 7 сейчас с пометкой `(уточнить)`. Дизайнер не позвонит, если не понимает свою маржу. Это единственная цифра, которая реально влияет на конверсию.

**2. Свои фото вместо моих.** Шесть кадров в пакете — сгенерированные визуализации: они показывают композицию, свет и что должно быть в кадре. Для сайта нужны ваши реальные изделия. Мои можно поставить временно, чтобы собрать страницу, но заменить до запуска рекламы.

**3. Перелинковка.** После публикации поставить ссылку «Дизайнерам интерьера» в футер и в B2B-блок на страницах `/aboutus`, `/toorder`, `/contacts`. Без входящих ссылок страница не соберёт трафик и не получит вес.

## Что делать с моими фото до замены

Можно использовать как есть — они не подписаны брендом и не выдают «сгенерировано».
Но три вещи стоит держать в голове:

- **Заменить в первую очередь обложку** — это первое, что видит дизайнер.
- **Кадр «размер» (`foto-05`)** — самый ценный: он показывает рулетку и попадание в нишу. Если есть возможность снять свой такой же — снимите, это сильнее любого текста.
- **Палитра (`foto-03`)** — как только сделаете настоящую выкладку образцов, сфотографируйте сверху и замените.

---

## Если что-то не сходится

- **На тарифе Personal нет `T-cards`** — собирается блоками `T-1040` / `T-1060` (плитки) или `T-text` с таблицей. Рисунок остаётся тот же, меняется только элемент.
- **Таблица уезжает на мобильном** — в `PDF-1` таблицы свёрстаны как на макете; если Tilda не тянет, разбейте на карточки по 3 строки или сделайте скриншот таблицы.
- **Нужен другой порядок блоков** — скажите, пересоберу макет под новую последовательность, тексты при этом не придётся переписывать.

## Как пересобрать PDF самому

Если правите текст в `TEKST-dlya-Tilda.md` или `README.md`:

```
pip install reportlab python-docx
python -c "import md2pdf; md2pdf.build(['TEKST-dlya-Tilda.md'],'PDF-1-tekst-pod-kopirovanie.pdf','Сотрудничество: текст под копирование','Страница /sotrudnichestvo · для сборки в Tilda',meta=['Основная ЦА — дизайнеры интерьера','27 октября 2026'],drop_first_h1=True)"
python make_pdf_maket.py     # после make_maket.py, если меняли макет
```

Word-версии: `python md2docx.py` — внутри функция `build()` с теми же аргументами.
Шрифт PDF — Manrope, он встроен в файл, на чужом компьютере ничего ставить не нужно.
