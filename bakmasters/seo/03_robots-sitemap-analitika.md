**Дата:** 15.10.2026 · Домен: `https://bakmasters.su`

---

## 1. robots.txt

### Что сейчас
```
User-Agent: *
Disallow: /page27109783.html
Disallow: /mistake
Disallow: /tilda/form*
... (служебные /tilda/*)
Disallow: /*_escaped_fragment_*
Disallow:

Sitemap: https://bakmasters.su/sitemap.xml
Sitemap: https://bakmasters.su/sitemap-store.xml
Host: https://bakmasters.su
```

**Проблемы:**
1. `Host:` — устаревшая директива, Яндекс не поддерживает её с марта 2018 года. Вредит не сильно, но выглядит как заброшенный сайт.
2. Пустая `Disallow:` в конце — бессмысленная строка.
3. **Главное:** `Disallow: /page27109783.html` закрывает одну техническую страницу, а ещё девять (`page27327196.html`, `page27338356.html`, `page27327258.html`, `page27327297.html`, `page27328559.html`, `page27328568.html`, `page27338359.html`, `page27338363.html`, `page27338370.html`) и `/f` — открыты и при этом лежат в `sitemap.xml`. То есть сайт сам отдаёт поисковику мусор.
4. Нет `Clean-param` — UTM-метки плодят дубли URL в индексе.

### Что должно быть (после удаления технических страниц)
```
User-Agent: *
Disallow: /tilda/
Disallow: /page*
Disallow: /f
Disallow: /*?
Clean-param: utm_source&utm_medium&utm_campaign&utm_content&utm_term&yclid&gclid&fbclid

Sitemap: https://bakmasters.su/sitemap.xml
Sitemap: https://bakmasters.su/sitemap-store.xml
```

При переезде на `.ru` — заменить домен во всех строках и убрать `Disallow: /page*`, если к тому моменту технических страниц не останется.

⚠️ `Disallow: /*?` закрывает все URL с параметрами. Проверьте после внедрения, что корзина и фильтры каталога продолжают работать корректно в глазах робота (они и не должны индексироваться).

### Как править в Tilda
Tilda генерирует `robots.txt` автоматически. Порядок действий:
1. **Удалить технические страницы** из проекта («Страницы» → страница → «Удалить») — тогда они уйдут и из sitemap, и из robots.
2. Для страниц, которые нужно оставить, но не индексировать: «Настройки страницы» → флаг **«Не индексировать страницу»** (Tilda добавит `noindex` и уберёт её из sitemap).
3. Возможность отредактировать сам файл `robots.txt` и добавить `Clean-param` зависит от тарифа и версии интерфейса — проверьте «Настройки сайта → SEO / Ещё». Если правка недоступна, пункты 1–2 решают 90 % проблемы, а `Clean-param` можно эмулировать canonical-ссылками.
4. После любых изменений **опубликовать сайт** — sitemap и robots перегенерируются при публикации.
5. Проверить результат: открыть `https://bakmasters.su/robots.txt` и `https://bakmasters.su/sitemap.xml` в режиме инкогнито.

## 3. Индексация и Яндекс Вебмастер

**Сделать один раз:**
1. Добавить сайт в Яндекс Вебмастер (`webmaster.yandex.ru`), подтвердить права (мета-тег в HEAD через «Настройки страницы → Дополнительно» для главной, или DNS/TXT-запись, или файл).
2. Указать **региональность: Москва** («Информация о сайте → Региональность») — критично для локальной выдачи и для запросов с «купить в Москве».
3. Отправить оба sitemap.
4. Проверить «Индексирование → Страницы в поиске»: сколько страниц реально в индексе, какие исключены и почему.
5. Проверить «Индексирование → Исключённые страницы» — после удаления технических страниц они должны попасть в «Удалённые» или «Не найдено (404)».
6. Использовать «Переобход страниц» для главной, каталога и новых посадочных (лимит — несколько URL в сутки).
7. «Анализ поисковых запросов» — снимать позиции и показы раз в неделю в таблицу, это ваша базовая линия для оценки эффекта.
8. После чистки — «Инструменты → Проверка robots.txt» и «Проверка структурированных данных».

**Отдельно:** инструмент «Переезд сайта» в Вебмастере понадобится при смене домена — включать после того, как новый домен уже работает и редиректы настроены.

## 4. Google Search Console

1. Добавить ресурс (`search.google.com/search-console`): тип «Ресурс с префиксом URL» — `https://bakmasters.su/`, подтвердить мета-тегом в HEAD.
2. Отправить sitemap.
3. Проверить «Покрытие/Страницы»: сколько проиндексировано, есть ли дубли, ошибки 404.
4. После внедрения разметки — «Расширенные фрагменты» (FAQ, Товары, Отзывы).
5. При переезде — «Настройки → Изменение адреса».

⚠️ Google даёт заметно меньше трафика в этой нише, чем Яндекс, но Rich Results по товарам (цена, наличие, рейтинг) работают именно там — для карточек товаров это стоит сделать.

## 5. Яндекс Метрика — счётчик и цели

**Установка:** «Настройки сайта → Аналитика → Яндекс Метрика» — вставить номер счётчика, включить Вебвизор, карту скроллинга и карту кликов.

**Цели, которые нужно настроить сразу** (без них невозможно понять, работают ли правки):

| № | Цель | Тип | Что даёт |
|---|---|---|---|
| 1 | Отправка любой формы | JavaScript-событие `form_submit` (Tilda умеет отправлять событие; либо цель «Отправка формы» по идентификатору конкретной формы) | Базовая конверсия сайта |
| 2 | Клик по WhatsApp | Переход по ссылке, содержащей `wa.me` | Основной канал для ручной работы |
| 3 | Клик по Telegram | Переход по ссылке, содержащей `t.me` | — |
| 4 | Клик по телефону | Переход по ссылке, содержащей `tel:` | Звонки, особенно с мобильных |
| 5 | Добавление товара в корзину | Событие корзины Tilda Store (включить передачу данных электронной коммерции в настройках магазина) | Воронка магазина, средний чек |
| 6 | Оформление заказа | Событие Tilda Store «заказ оформлен» | Конверсия каталога |
| 7 | Переход в каталог | Клик по ссылке `/shop` | Верх воронки |
| 8 | Просмотр страницы «На заказ» | Просмотр URL `/toorder` | Интерес к индивидуальным заказам |

**Дополнительно:**
- Включить **электронную коммерцию (ecommerce)** для Tilda Store — тогда в Метрике появятся данные по товарам, доходу и среднему чеку.
- Настроить **сквозную аналитику по UTM** (метки в ссылках из соцсетей и рекламы).
- Поставить **сегменты**: мобильные vs десктоп, из поиска vs прямые заходы.
- Проверить, что после установки счётчика данные реально идут (открыть сайт, посмотреть отчёт «Посетители онлайн»).

⚠️ Если счётчика сейчас нет — ставьте его до начала любых работ: без «до» невозможно показать эффект от изменений.

## 8. Скорость и мобильные

1. Прогнать PageSpeed Insights для `https://bakmasters.su/` и `/shop` (mobile + desktop): `pagespeed.web.dev`. Зафиксировать цифры «до».
2. Типовые меры для Tilda:
   - заменить тяжёлые JPG (`DSC_*.JPG`, сейчас отдаются в полном размере через `static.tildacdn.com/.../-/empty/`) на сжатые версии ≤ 200–300 КБ и разрешить Tilda отдавать WebP;
   - убрать лишние фоновые видео и автозапуск музыки на `/aboutus`;
   - сократить число блоков-галерей на главной (сейчас их несколько подряд, каждая тянет десятки изображений);
   - проверить, что ленивая загрузка включена (Tilda делает по умолчанию — убедиться, что первый экран не грузит весь каталог);
   - ограничить число подключаемых шрифтов до двух начертаний.
3. Цель: Performance mobile ≥ 60 через 30 дней, ≥ 80 через 90 дней.
