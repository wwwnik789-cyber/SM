# Реализация новых разделов на сайте (React-сборка)

Дата: 30.10.2026

Материалы из `site_content/`, `docs/konstruktsii/` и `visualizations/` перенесены в рабочее React-приложение SM-Production.

## 1. Страница «Брус-баннер на скрытом каркасе»

- **URL:** `/uslugi/brus-banner`
- **Компонент:** `src/pages/BrusBanner.jsx`
- **Данные:** `src/data/brusBanner.js`
- **Медиа:** `public/media/brus/` (9 визуализаций из `visualizations/brus-banners/`)

Блоки страницы: hero с УТП и ценой «от 16 500 ₽» → 6 преимуществ → сравнительная таблица «Джокер vs брус-баннер» →
7 сценариев применения → галерея работ с лайтбоксом → технические характеристики + варианты исполнения →
таблица цен с монтажом/без + акция с бесплатной доставкой → 6 этапов работы → FAQ (8 вопросов) →
связанные услуги → CTA с заявкой.

## 3. Точки входа и перелинковка

| Место | Что добавлено |
|---|---|
| `src/App.jsx` | статические маршруты для обеих страниц (выше `/uslugi/:slug`) |
| `src/data/services.js` | услуги «Брус-баннер» (категория «Конструкции») и «Брендирование офисов и ресепшн» (категория «Интерьер»); новые категории в фильтре |
| Шапка сайта | мега-меню «Услуги» + пункт «Стойки ресепшн» в «Производстве» |
| Футер | ссылки в колонке «Услуги» |
| Главная | промо-баннер нового направления (по рекомендациям из `04_razmeshenie-razdela-na-sajte.md`), быстрая карточка «Брус-баннер», обновлённая бегущая строка |
| `src/lib/search.js` | обе страницы в командной палитре (Ctrl/Cmd + K) |
| `src/pages/Sitemap.jsx`, `public/sitemap.xml`, `public/llms.txt` | новые URL для навигации, SEO и AI-краулеров |
| `src/data/faq.js` | 2 общих вопроса про брус-баннер и брендирование офисов |
| `scripts/smoke.mjs` | новые маршруты в SSR-смоук |

