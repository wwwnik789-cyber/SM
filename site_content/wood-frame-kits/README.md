# Баннеры на деревянных каркасах

В каждой папке ровно три готовых изображения для карточки товара. `dimensions.jpg` — фотография конструкции с нанесёнными прямо на изображение размерными линиями; `front.jpg` и `angle.jpg` — фотографии без дополнительных надписей.

- `400x300x40`: ширина 400 см, высота 300 см, глубина 40 см
- `300x250x40`: ширина 300 см, высота 250 см, глубина 40 см
- `250x300x4`: ширина 250 см, высота 300 см; глубина не указывается, поскольку у плоской конструкции её нет
