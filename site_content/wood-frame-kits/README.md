# Баннеры на деревянных каркасах

В папках размещены исходные фото без добавленных подписей и размерной графики. Сами визуалы не редактировались.

- `400x300x40/` — предоставленные фотографии комплекта 400 × 300 × 40 см
- `300x250x40/` — предоставленные фотографии комплекта 300 × 250 × 40 см
- `250x300x4/` — предоставленные фотографии плоского комплекта 250 × 300 см; глубина не указана

В загруженных исходниках для каждого размера есть по два фото.
