# Баннеры на деревянных каркасах

В каждой папке ровно три визуала без размерных подписей: `front.jpg`, `angle.jpg`, `side.jpg`.

- `400x300x40`: полотно с пропорцией 4:3, объёмная конструкция с боковым возвратом
- `300x250x40`: полотно с пропорцией 6:5, объёмная конструкция с боковым возвратом
- `250x300x4`: полотно с пропорцией 5:6, плоская конструкция; глубина 4 см показана как тонкая кромка, баннер закрывает каркас

Размеры поверх изображений не нанесены — их можно добавить в карточках товаров.
