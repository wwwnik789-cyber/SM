# Правки страницы «Оформление сцен»

Страница: https://sm-production.ru/uslugi/oformleniye-stseny
Формат: готовые тексты для Tilda. Каждый блок — что заменить и на что.

---

## 1. Критично: заголовок блока про фотозоны

**Найти:**

```
Осуществляем полный цикл работ по производству фотозон
```

**Заменить на:**

```
Полный цикл работ по оформлению сцен
```

**Почему:** на странице сцен стоит заголовок от другой услуги. Это первый признак
шаблона, который замечают закупщики ивент-агентств.

---

## 2. Критично: сломанная карусель

В блоке «Как мы можем вам помочь в оформлении сцен?» пункт
«Оформление экранов (каше экрана)» повторяется четыре раза подряд.

**Что сделать:** оставить четыре уникальные карточки в таком порядке —

1. Оформление экранов (каше)
2. Раус сцены
3. Брендирование передней и боковых частей сцены
4. Дополнительное оборудование

```

Как создать идеальную фотозону: чек-лист из 7 пунктов — /blog/kak-sozdat-idealnuyu-fotozonu
Полный цикл производства — /blog/polnyj-cikl-proizvodstva
Услуга «Каше для экрана» — /uslugi/kashe-dlya-ekrana
Услуга «Раус-сцены» — /uslugi/raus-stseny
```

**Почему:** страница услуги сейчас не связана с блогом и соседними услугами.
Перелинковка передаёт вес и удерживает посетителя внутри сайта.

## Порядок работ

1. Заменить заголовок про фотозоны (пункт 1) — это минута, эффект сразу.
2. Починить карусель (пункт 2).
3. Добавить блоки 3–5: состав, стоимость, сроки.
4. Вставить кейсы (пункт 7) — они уже есть в репозитории, нужны только фото.
5. Перелинковка (пункт 8) — после публикации статьи.
6. Мелочи (пункт 9).
