# Сборка и проверка единого PDF

Основной результат — `../sm-production-nashi-tseny-instruction.pdf`: **42 страницы A4**. Alt находятся сразу после обложки, на с. 2–8; быстрый маршрут — с. 9, одно оглавление — с. 10. Это один полный документ, не набор отдельных инструкций.

## Новая структура

Три ещё не названных варианта баннеров на деревянном каркасе → восемь строк стандартных цен CL46 → ссылка на существующий калькулятор своих размеров → один блок PressWall «Джокер» / RollUp / виндеров → аренда и прежние завершающие разделы.

Названия, различия и фотографии трёх вариантов не предоставлены. Генератор не назначает им три произвольных размера. Предыдущие восемь обложек дерева и два шаблона X-баннеров — резерв, не обязательные публичные карточки. Для текущей рекомендуемой схемы описаны пять ST340C; штатные настройки первой витрины нужно проверить в редакторе.

## Источники сборки

- `../README.md` — порядок блоков, настройка Tilda, аренда, мебель, цены и заявки, неизменённая таблица фрезеровки.
- `../seo-setup.md` — полный раздел 10: обновлённые Title/Description, H1/H2/H3, SEO товаров, alt и индексация. Полностью вставляется в PDF вместо краткой ссылки из README.
- `../cl46-table.md` — полный раздел 14: восемь строк, `60%;40%`, мобильный режим, применимость цены к варианту и реальная ссылка калькулятора. Тоже полностью включается в PDF.
- `../assortiment-plan.csv` — **36 позиций новой страницы**: 3 варианта, 11 конструкций, 2 оборудования, 10 стульев и 10 кресел. Цены пустые, публикация отключена. Ведомость включается в приложение А; это не прежняя матрица 42 кандидатов.
- `../image-alt-register.csv` — **46 записей**: все 43 прежние пары файл/позиция → alt плюс три новых шаблона. 36 активных позиций совпадают с новой ведомостью; 10 записей помечены резервом. Всего 19 готовых alt по существующим файлам (11 активных и 8 резервных), 27 условных текстов (25 активных и 2 резервных). Все таблицы — в начале PDF, не в приложении в конце.
- Согласованные визуализации из `visualizations/catalog/` — обложка и приложение Б. Исходные изображения не меняются; восемь обложек дерева явно показаны как резерв.

Ссылки на все 20 внешних моделей мебели сохранены в основном тексте. Эти модели не подтверждают парк SM или права на фотографии. CSV — редактируемые исходники, а не готовый импорт Тильды и не дополнительные обязательные файлы для чтения.

## Сборка

```bash
python -m pip install --target .arena/pdf-libs -r site_content/05_nashi-tseny-st340c/scripts/requirements.txt
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/build_pdf.py
```

Нужны DejaVu Sans, DejaVu Sans Bold и DejaVu Sans Mono в `/usr/share/fonts/truetype/dejavu/`. Кириллические шрифты встраиваются, текст можно копировать. Оглавление, 35 закладок (включая вложенные alt/SEO), 51 внутренний переход и 58 внешних ссылок кликабельны.

## Проверка

```bash
python -m pip install --target .arena/pdf-libs -r site_content/05_nashi-tseny-st340c/scripts/requirements-qa.txt
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/check_pdf.py

# Рендер всех страниц для визуального контроля
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/check_pdf.py --render-dir .arena/prices-restructure-qa
```

Проверяется текущая редакция:
- 42 страницы A4, одно оглавление и полная таблица фрезеровки на одной странице;
- последовательность глав и элементов схемы: три варианта → CL46 → калькулятор → общий каталог → аренда;
- отсутствие назначенных размеров/файлов у трёх неизвестных вариантов;
- 36 строк плана, единый раздел для порядка 4/4/3, отсутствие X-баннеров в активной выдаче, пустые неутверждённые цены;
- все 46 alt именно на с. 2–8, наличие 19 файлов, отделение 36 активных от 10 резервных записей, отсутствие незаполненных скобок в готовых alt;
- обновлённые SEO-поля и возможность копировать кириллицу;
- точные 13 строк / 52 ставки фрезеровки и минимум 10 000;
- восемь строк CL46, шапка и ширина `60%;40%`;
- четыре реальные кликабельные ссылки на страницу калькулятора, без выдуманного якоря;
- все 20 мебельных ссылок, корректные внутренние назначения и закладки;
- отсутствие текста за полями страницы.

Открытие страницы калькулятора и наличие полей были проверены при подготовке; офлайн-проверка PDF не выполняет расчёт и не тестирует форму. Арифметика, актуальность коэффициентов и передача результатов требуют отдельного теста на сайте. Ссылка не подставляет выбранный вариант автоматически.
