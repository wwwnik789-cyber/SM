# Сборка и проверка единого PDF

Основной результат — `../sm-production-nashi-tseny-instruction.pdf`: **41 страница A4**, а не подборка разрозненных инструкций.

## Источники сборки

- `../README.md` — структура, настройка ST340C, мебель, цены и заявки, неизменённая таблица фрезеровки.
- `../seo-setup.md` — полный раздел 10: готовые SEO-тексты, заголовки, alt, индексация и примеры карточек. Полностью вставляется в PDF вместо краткой ссылки из README.
- `../cl46-table.md` — полный раздел 14: строки, ширина 60/40, мобильный режим и кнопка. Тоже целиком вставляется в PDF.
- `../assortiment-plan.csv` — прежние 42 строки с незаполненными ценами; ведомость включается в приложение А.
- `../image-alt-register.csv` — все 43 строки выводятся в приложении В: 19 готовых alt по существующим файлам, 24 условных текста для ещё не утверждённых фотографий. «Бриз» — дополнительный кандидат вне прежней матрицы 42 позиций.
- Согласованные визуализации из `visualizations/catalog/` — обложка и приложения. Оригинальные файлы не меняются.

Ссылки на все 20 внешних моделей мебели остаются в основном тексте. CSV — дополнительные редактируемые исходники, не обязательные файлы для чтения и не готовый импорт Тильды.

## Сборка

```bash
python -m pip install --target .arena/pdf-libs -r site_content/05_nashi-tseny-st340c/scripts/requirements.txt
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/build_pdf.py
```

Нужны DejaVu Sans, DejaVu Sans Bold и DejaVu Sans Mono в `/usr/share/fonts/truetype/dejavu/`. Кириллические шрифты встраиваются; текст можно копировать. Оглавление, 34 закладки (включая вложенные пункты SEO), 59 внутренних переходов и 58 внешних ссылок кликабельны.

## Проверка

```bash
python -m pip install --target .arena/pdf-libs -r site_content/05_nashi-tseny-st340c/scripts/requirements-qa.txt
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/check_pdf.py

# Необязательно: рендер всех страниц для визуального контроля
PYTHONPATH=.arena/pdf-libs python site_content/05_nashi-tseny-st340c/scripts/check_pdf.py --render-dir .arena/prices-seo-final
```

Проверяется текущая редакция:
- 41 страница A4, одно оглавление и целая таблица фрезеровки на одной странице;
- Title/Description главной страницы, сохранение кириллицы для копирования;
- все 43 alt внутри PDF и наличие 19 сопоставленных исходных файлов;
- 42 позиции прежнего плана, пустые неутверждённые цены и статус «не публиковать»;
- точное сохранение всех 13 строк / 52 ставок фрезеровки и минимума 10 000;
- восемь строк CL46, шапка и `60%;40%`;
- 20 мебельных ссылок, внутренние переходы и закладки;
- отсутствие текста за полями страницы.

После изменений содержания и повторной сборки обновляйте число страниц/контрольную сумму в README при необходимости. Содержимое также проверено визуально. Генератор не публикует Тильду, не рассчитывает наценки, не утверждает наличие/права и не меняет изображения. `.arena/` — только локальные зависимости и рендеры; в Git не добавлять.
