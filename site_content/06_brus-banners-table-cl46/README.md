Это инструкция по ручной настройке **CL46 «Таблица»** из категории «Колонки», не ещё одна инструкция по товарному каталогу ST340C. Самостоятельно читать Markdown или скачивать CSV для выполнения шагов не нужно: все строки и пояснения находятся внутри PDF.

## Что внутри

1. Образец таблицы из двух колонок: размер и стоимость.
2. Путь к CL46 и три готовых поля для копирования: шапка, восемь строк, ширина `60%;40%`.
3. Рекомендации по оформлению SM и настройка сжатия таблицы на мобильных устройствах.
4. Лист для согласования восьми цен и шаблон пояснения комплектации, доставки, монтажа и НДС.
5. Кнопка заявки через T173, создание якоря `raschet-brus`, проверка формы и ручная сверка со ST340C.
6. Проверка перед публикацией, типовые ошибки и кликабельные ссылки на справку Тильды.

**Согласованный порядок размеров, ширина × высота:** 2 × 2; 2 × 2,5; 3 × 2; 3 × 2,5; 4 × 2,5; 4 × 3; 5 × 2,5; 5 × 3 м.

Числовые цены и состав базового комплекта пользователь не предоставлял. Они не выдуманы: в образце стоит рабочая метка «УТОЧНИТЬ», в ведомости оставлены поля. В PDF прямо указано не публиковать эти метки и не заменять неизвестную цену нулём. Условия аренды, наличие, налоговый режим и включённые услуги не подразумеваются.

`raschet-brus` — предлагаемое имя нового якоря, не ID существующего блока или уже настроенная ссылка на сайте. Автоматической подстановки выбранной строки в форму и синхронизации CL46 с Каталогом эта схема не создаёт.

## Сборка и контроль

```bash
python -m pip install -r site_content/06_brus-banners-table-cl46/scripts/requirements.txt
python site_content/06_brus-banners-table-cl46/scripts/build_pdf.py

# Проверка готового файла; необязательно для обычного чтения PDF
python -m pip install -r site_content/06_brus-banners-table-cl46/scripts/requirements-qa.txt
python site_content/06_brus-banners-table-cl46/scripts/check_pdf.py
```

Сборка использует кириллические шрифты DejaVu из `/usr/share/fonts/truetype/dejavu/` и встраивает используемые начертания в PDF. Текст можно выделять и копировать; есть шесть закладок, пять внутренних переходов и четыре внешние ссылки на три официальные страницы.

Проверяются шесть страниц A4, порядок размеров, точный текст строк CL46, шапка, `60%;40%`, доступность кириллицы для копирования, ссылки, закладки и отсутствие текста за полями страницы. Шесть страниц также проверены визуально.
