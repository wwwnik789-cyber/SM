# Визуализации фотозоны «РОЛЬФ» — 22.10.2026

Клиентские визуализации по позиции 2 КП (отрисовка дизайна, визуализация, фотопривязки).
Генерируются скриптом `scripts/commercial/viz_photozone.py` (собственный программный
3D-рендер: numpy + PIL, перспективная камера, z-буфер, Lambert + эмиссия + точечные
источники, bloom, отражение в полу, воздушная перспектива).

## Геометрия сцены (в метрах)

- Стена фотозоны: X 0…12,000, Y 0, высота 3,500; обшивка АКП GROSSBOND 3 мм, 9937 G.
- Объёмный каркас (фотобокс): X 5,000…12,000, глубина 2,500, высота 2,500, сталь в окраске,
  4 стойки (X 5,0 / 6,3 / 9,7 / 12,0), открыт в зал.
- Лайтбоксы: 10 шт., шаг 650, ширина 300, высота 2 000, отметка низа +300; лицевая плоскость
  светящаяся, корпус глубиной 120.
- Фальш-потолок: 7 000 (по стене) × 5 000 (в глубину), подвес на отметке +3 200,
  обшивка АКП + Oracal 641 073M, три линейные линии подсветки.
- Буквы «РОЛЬФ»: 1 500 × 400, X 7,250…8,750, Z +2 620…+3 020, объёмный ПВХ, белые.

## Пересборка

```bash
python3 scripts/commercial/viz_photozone.py
```

Скрипт перезаписывает все четыре файла в `docs/kommerciya/2026-10-22-rohl-fotozona/viz/`
и печатает пути сохранения. Визуализации также встроены в клиентский DOCX:
`docs/kommerciya/2026-10-22-rohl-fotozona/01_kommercialnoe-predlozhenie.md` → раздел 6.

## Оговорка

Визуализация носит ознакомительный характер: показывает расположение, пропорции, цвет
и уровень света. Финальная геометрия — по рабочим чертежам и файлам для ЧПУ (позиция 1 КП).
Фотопривязка на архив снимков площадки выполняется после получения снимков от клиента.
