# Фоны на гексагональной текстуре — для презентаций

Набор фонов на основе гексагональной текстуры заказчика (`source-hex.png`).
12 вариантов под разные роли слайдов, 16:9, в двух разрешениях, в фирменной палитре SM.

**Готовые файлы:** `fon/*.jpg` (1920×1080) и `fon-2x/*.jpg` (2560×1440).
**Всё одним архивом:** `SM-Fony-hex-JPEG.zip` (9,4 МБ).
**Обзор всех 12 вариантов:** `preview-bez-teksta.jpg`.

Только JPEG. Никакого текста, логотипов и подписей внутри самих фонов —
это чистые подложки под вашу вёрстку.

---

## Главное про качество

Плитка **не растянута из исходника**. Он 1360×768 — при увеличении до 1920 гексы поплыли бы.
Поэтому гексагон рисуется процедурно: SDF по шести плоскостям, фаска с направленным светом,
случайная яркость каждой плитки, тонкая щель между плитками, сглаживание кромки.

Отсюда:
- резкость на любом разрешении, вплоть до 4K — просто поменяйте размер в `build()`.
- стыки без наложений и «двойных контуров» — частая беда при размножении картинки.
- масштаб плитки задаётся одним числом: `R` в `hex_texture()` (сейчас `w / 24`).

Исходник при этом остаётся в репозитории как референс геометрии и материала.

## Читаемость проверена цифрами

В `build_fony.py` есть функция `contrast_report()`: она считает контраст белого текста
`#F4F2EC` в тех зонах, под которые сделаны фоны (WCAG: ≥4.5 для обычного текста, ≥3.0 для крупного).

Текущий результат:

```
01: заголовок слева       13.1:1   OK
02: центр под цифру       10.4:1   OK
03: текст слева           16.1:1   OK
04: текст справа          16.0:1   OK
05: вся площадь           15.8:1   OK
06: зона под цифры        15.0:1   OK
07: центр цитаты          10.4:1   OK
09: зона под фото          9.8:1   OK
10: центр финала          11.5:1   OK
11: текст слева           16.0:1   OK
```

Все зоны сильно выше нормы — текст читается и на проекторе с низкой яркостью.
На светлом `08-svetlyy` текст должен быть тёмным (`#0A0A0D`), не белым.

## Как пересобрать

```bash
pip install pillow numpy
python3 build_fony.py      # фоны 1920 и 2560 + контактный лист + отчёт о контрасте
```

Сборка детерминирована: фиксированные зёрна (`R_SEED`), поэтому повторный запуск даёт те же файлы.

### Что менять

- **Размер плитки** — параметр `R` в `hex_texture()`; сейчас `w / 24` ≈ 80 px радиуса.
- **Материал** — `FACE_DARK` / `GAP_DARK` (тёмный) и `FACE_LIGHT` / `GAP_LIGHT` (светлый).
- **Направление света** — `light_from` в `hex_texture()`, в долях вектора.
- **Зоны тени под текст** — маски `m` в `build()`: это просто функции от координат.
- **Цвета** — `ACCENT` (#FF4D1C) и `ACID` (#D8FF3E) в начале файла.
- **Разрешения** — кортеж в `main()`: `((OUT, (1920, 1080)), (OUT2, (2560, 1440)))`.

## Как использовать

1. Вставка → Рисунки → выбрать фон из `fon/`.
2. Правой кнопкой → «Изменить рисунок» → растянуть на слайд или задать как фон слайда
   (Дизайн → Формат фона → Рисунок).
3. Если нужен более тёмный вариант — наложите прямоугольник `#0A0A0D` с прозрачностью 30–50%.
4. Для 4K-проекторов берите `fon-2x/`.

Шрифты: Unbounded (заголовки) и Manrope (текст) — в `../ca-avtosalony/02_prezentaciya/fonts/`.
Палитра: фон `#0A0A0D`, карточки `#14141C`, текст `#F4F2EC`, акцент `#FF4D1C`, кислотный `#D8FF3E`.
