# Как править презентацию самому

В папке лежат две версии одного и того же макета — 15 слайдов, 16:9.

| Файл | Для чего | Чем править |
|---|---|---|
| `SM-Production_Brending-avtosalonov.pptx` | **Для правок**: каждый текст и фото — отдельный объект | PowerPoint, Keynote, Google Slides, LibreOffice |
| `SM-Production_Brending-avtosalonov.pdf` | Для отправки письмом | — |

**Важно:** PDF и PPTX собираются из одного кода (`build_pdf.py` / `build_pptx.py`) — правки
в PPTX не попадут в PDF автоматически. Если нужен новый PDF для рассылки, пришлите
исправленный PPTX или список правок: пересоберём за минуту.

---

## Шрифты (поставить один раз)

Вёрстка рассчитана на **Unbounded** и **Manrope**. Без них PowerPoint подставит свой
шрифт, и текст «поедет».

1. Откройте папку `fonts/`.
2. Выделите все `.ttf` → правый клик → **Установить** (или «Установить для всех пользователей»).
3. Перезапустите PowerPoint.

Скачать всё одним архивом: `../SM-fonts-Unbounded-Manrope.zip`

## Что можно править без опаски

- **Текст** — любой: клик по надписи и печать. Блоки уже с нужными переносами строк.
- **Цены** — ищите «от 250 000 ₽» и т.п., меняйте цифры.
- **Фотографии** — правый клик → «Изменить рисунок» → выбрать новый файл. Размер
  и скругление углов сохранятся.
- **Порядок слайдов** — перетаскиванием в панели слева.
- **Заметки к слайдам** — в PPTX уже заполнены подсказками для менеджера
  (вид → «Страницы заметок»).

## Чего лучше не делать

- **Не меняйте шрифты** на другие — слетят переносы строк и вся сетка.
- **Не растягивайте фото** за угол вручную: пропорции уже обрезаны под макет.
  Если нужно другое кадрирование — «Обрезка» внутри рамки, а не растягивание.
- **Не сдвигайте колонтитул** (логотип + номер слайда внизу) — стоит на одной
  линии на всех слайдах.
- Если текст не влезает, уменьшайте **кегль на 1–2 pt**, а не ширину блока.

## Если нужна другая версия

Всё собирается скриптами (нужны `reportlab`, `python-pptx`, `pillow`):

```bash
python3 build_pdf.py     # PDF для рассылки
python3 build_pptx.py    # редактируемый PowerPoint
python3 check_pptx.py    # проверка вёрстки: рендер всех слайдов в /tmp/pptx-preview
```
