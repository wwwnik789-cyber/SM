# Haval — оформление дилерского центра (версия 2)

Дата: 27.10.2026
Папка: `04_haval/` · 10 кадров, JPEG q94 + `preview.jpg`

Комплект под бренд **Haval** (Great Wall Motor): зона ресепшн, объёмные логотипы
с подсветкой, бренд-панели, навигация, подвесы, информационные стойки, PressWall
на модельный ряд, фотозона и фасад.

**Что изменилось после первой версии.** Первая серия была снята «как в жизни» —
серые стены, рабочий беспорядок, видимые провода и удлинители, пустые плашки без
логотипа. Замечание принято: выглядело как из 90-х, брендинг отсутствовал.
Версия 2 — **премиальный светлый шоурум**: полированный керамогранит, графитовые
панели с бирюзовой световой линией, чёрный open-cell потолок, много дневного
света. Все кадры вычищены: **ни проводов, ни удлинителей, ни кабелей, ни коробок,
ни стремянок**. Логотип **HAVAL присутствует** на всех носителях.

## Изделия: реальные стойки заказчика

Ваши фото (`izdeliya/stoyki-1.jpg`, `izdeliya/stoyki-2.jpg`, 3024 × 4032) —

### Исполнение 1 — «Панель» (на фото слева)

| Параметр | Значение |
|---|---|
| Материал | акрил прозрачный (cast), 8–10 мм |
| Корпус | две боковые панели-«ноги», соединённые с основанием и карточкой |
| Основание | акриловая пластина с диагональной пятой-распоркой (треугольник в плане) |
| Карточка | наклонная, два слоя акрила 3 мм, по углам держатели-винты |
| Вкладыш | чёрный, с золотым тиснением |
| Высота (оценка по фото) | ~1350–1450 мм, карточка ~420 × 300 мм |
| Устойчивость | центр тяжести смещён назад за счёт диагональной пяты |

### Исполнение 2 — «Шпильки» (на фото справа)

| Параметр | Значение |
|---|---|
| Каркас | четыре металлические стойки-шпильки Ø 6–8 мм по углам |
| Карточка | в акриловой рамке, наклон 10–15°, угловые держатели |
| Основание | прозрачная акриловая пластина 8 мм + треугольная распорка |
| Вкладыш | чёрный, с золотым тиснением |
| Высота (оценка по фото) | ~1300 мм |

**Что это даёт в КП:** оба исполнения — модульные, карточка меняется без
демонтажа (вынул вкладыш — поставил новый), основание не сверлит пол, вес
позволяет переставлять стойку силами одного человека. Для Haval вкладыш
делается в фирменной сетке: чёрное поле `#0F0F0F`, бирюзовая линия `#72D6D8`,
логотип из `brand/` — то есть те же носители, что на визуализациях.

Точные габариты и толщины фиксируются по вашим замерам — на фото есть ракурс,
но нет масштабной линейки.

## Что входит в комплект по позициям

1. **Фриз фасада:** световой короб на графитовом основании, съёмная лицевая
   панель — под смену макета при ребрендинге или новой модели.
2. **Зона ресепшн:** стойка с бирюзовой световой кромкой и подсвеченной лицевой
   панелью, тумба, скрытая проводка, световая панель на стене.
3. **Объёмный логотип:** панель на дистанционных держателях с контражуром,
   обслуживаемый доступ к светодиодам.
4. **Бренд-панели:** 3–4 полотна в единой рамной системе, скрытый каркас,
   сменные полотна и лайтбоксы.
5. **Навигация:** напольный указатель, подвесные указатели на тросах, таблички,
   пиктограммы по брендбуку.
6. **Подвесы:** световые короба на тросовой подвеске к несущему перекрытию,
   доступ к светодиодным линейкам через съёмную грань.
7. **Инфостойки:** интерактивный тотем (тач + ПО дилера), наклонная стойка,
   стойка печатных материалов; акриловые стойки — по вашим фото.
8. **PressWall:** матовое полотно без блика на скрытом каркасе, разборный,
   под смену изображения модели.
9. **Фотозона:** портал-рамка с подсветкой, подиум с подсветкой кромки,
   плашка под логотип.
10. **Фасад:** световой короб, объёмные элементы, монтаж с автовышки.

## Правила, которые соблюдены

- **Логотипа SM нет** — работаем под бренд клиента.
- **Логотип Haval есть** и стоит на своих носителях: стена ресепшн, панель над
  стойкой, лайтбоксы, подвесы, плашка фотозоны, фриз фасада.
- **Никаких проводов, удлинителей, кабелей, коробок и стремянок** в кадре.
  Питание носителей — скрытая проводка, обслуживаемый доступ.
- **Текст не выдумываем:** слоганы бренда на макеты не наносятся без
  согласования с дилером. Интерфейсы на экранах — пиктограммы, без букв.
- **Чужих марок в кадре нет:** эмблемы и шильды на автомобилях убраны.
- **Сроки и гарантию** не обещаем, СПб не упоминаем (канон `01_koncepciya.md`).

## Как повторить / продолжить

Ядро промпта: *premium light showroom, polished porcelain floor, matte graphite
wall panels, thin mint-turquoise LED line, black open-cell grid ceiling, tall
windows with daylight, immaculate — no cables, no clutter*, носитель —
*blank illuminated panel*; логотип накладывается программно из `brand/`.
Запрет в промпте: *no text, no letters, no logos* — генератор всё равно иногда
дописывает латиницу, поэтому после генерации кадры проверяются на решётках
автомобилей и экранах.
