Дата: 27.10.2026
Папка: `06_kuby/` · **18 визуализаций** (2688 × 1792 и 1792 × 2688) + 3 обработанных фото + превью

Продолжение работы по автосалонам. У вас есть готовые брендированные кубы Haval
(стопки по 4–5 штук в шоуруме), но фотографии сняты на телефон: против света,

## 3. Как переснять кубы: протокол на 15 минут

1. **Свет:** снимать не против витрины. Развернуть стопку так, чтобы окно было
   сбоку (боковой свет читает грани), либо снимать вечером при включённом свете
   зала.
2. **Фон:** кубы поставить на свободную площадку, из кадра убрать шины, рюкзаки,
   стремянки, коробки.
3. **Точка:** телефон на уровне середины стопки, не снизу. Отойти на 2,5–3 м и
   снять на 2× — так меньше искажений перспективы, чем на широком.
4. **Кадры:** три обязательных — фронт стопки, три четверти, деталь грани
   (логотип + стык) с расстояния 1 м.
5. **Производство:** снимать кубы **до** упаковки в плёнку, стол протереть,
   в кадр пустить печатную машину фоном.
6. **Плёнка:** если без неё нельзя — снимать под углом 45°, тогда блики уходят
   в сторону, а не в объектив.
7. **Настройки:** сетка включена, HDR выключен, вспышка выключена, серия из
   5 кадров с разной экспозицией.

## Файлы и пересборка

- `brand_cubes.py` — наложение надписей и логотипа Haval на визуализации;
- `brand_other.py` — кубы под другие бренды (Chery, Geely, Lada, Jetour);
- `brand/` — PNG-логотипы брендов с прозрачностью;
- `autoface.py` — автопоиск грани куба по цвету (бирюза → квад);
- `find_faces.py` — отладка: компоненты бирюзы и их углы;
- `retouch.py` — обработка ваших фотографий;
- `src/` — исходные кадры до брендирования (1536 × 1024);
- `istochniki/` — ваши оригиналы (3024 × 4032 и 5712 × 4284).

```bash
/tmp/venv/bin/python brand_cubes.py   # пересобрать визуализации Haval
/tmp/venv/bin/python brand_other.py   # пересобрать кадры других брендов
/tmp/venv/bin/python retouch.py       # пересобрать фото
```
