## Как получить PDF (1 минута)

1. Открыть `02_prezentaciya/index.html` в браузере (Chrome).
2. `Ctrl+P` → «Сохранить в PDF» → **Портрет: выкл (альбомная)**,
   поля: **нет**, графика фона: **вкл** (или «Фоновая графика»).
3. Размер страницы подставится автоматически (16:9, 338,7×190,5 мм).
4. Полученный PDF (≤ 10 МБ) — вложение для писем из `03_pismo-menedzheram.md`.
