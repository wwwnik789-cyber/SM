**оперативно решать вопросы по брендингу**.

## 📄 Готовый PDF (для письма)

**`02_prezentaciya/SM-Production_Brending-avtosalonov.pdf`** — 15 слайдов, 16:9, 2,6 МБ.
Просто скачайте и приложите к письму. Ничего печатать не нужно.

Пересобрать PDF после правок текста:
```bash
cd 02_prezentaciya
python3 build_pdf.py          # нужны: reportlab, pillow
```
Шрифты лежат в `02_prezentaciya/fonts/` (Unbounded, Manrope — лицензия OFL,
файлы лицензий там же), поэтому сборка работает без интернета.
