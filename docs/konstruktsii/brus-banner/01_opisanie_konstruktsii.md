# Брус-баннер (баннер на скрытом деревянном каркасе)
## Основная информация
Брус-баннер — это премиальная рекламная конструкция, представляющая собой жесткий щит из деревянного бруса, обтянутый баннерной тканью или с нанесенной прямой печатью, при этом каркас полностью скрыт, а торцевая (боковая) часть составляет 20–40 см глубины, создавая эффект "объема" и парения стены.

Это флагманская конструкция SM Production, отличающаяся премиальным внешним видом и универсальностью применения.

---
## Технические характеристики
| Параметр                | Значение                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| **Материал каркаса**    | Строганый деревянный брус (сосновый), усиление по необходимости         |
| **Лицевая поверхность** | Баннерная ткань (матовая/глянцевая) с полноцветной печатью 1440 dpi, либо прямая УФ-печать на листовом материале (ПВХ 5-10 мм) |
| **Стандартные размеры** | 4×3 м, 5×3 м, 6×3 м, 3×3 м, 2×3 м (под заказ любые нестандартные размеры и пропорции, высота до 5 м) |
| **Глубина торца**       | 20 см (стандарт), 30 см, 40 см (для колонн и высоких конструкций)        |
| **Вес**                 | ~8-15 кг на 1 м² в зависимости от конфигурации                           |
| **Время производства**  | от 24 часов (срочный заказ), стандартно 2-3 рабочих дня                 |
| **Монтаж**              | 2-4 часа для стандартной конструкции, возможен монтаж за 1 день до мероприятия или в день проведения |
| **Транспортировка**     | Разборная конструкция, удобна для перевозки в любом транспорте           |
| **Возможность аренды**  | ✅ Есть (каркас можно переиспользовать, меняется только печать)         |

## Преимущества брус-баннера перед другими конструкциями
✅ **Премиальный внешний вид** — отсутствие видимых труб, креплений и складок ткани, идеально ровная поверхность. Выглядит значительно дороже и солиднее баннеров на системе Joker или Roll-Up стендов.

✅ **Любая форма и размер** — можно изготовить как стандартный прямоугольный баннер, так и фигурную конструкцию со сложной геометрией (как на проекте "Маяки будущего", "Коллекция счастливых дней")

✅ **Универсальность** — подходит для использования как в помещении, так и на улице (при обработке каркаса защитными составами)

✅ **Многоразовость** — каркас служит много лет, при повторном мероприятии достаточно заменить только печатную часть, что экономит бюджет клиента

✅ **Стабильность** — конструкция устойчива, не требует дополнительных растяжек и опор в большинстве случаев

✅ **Скорость монтажа** — бригада собирает баннер 5х3 м за 2–3 часа

✅ **Идеальная поверхность для фотосессий** — благодаря отсутствию бликов и складок это лучший выбор для press-wall и фотозон с фотографированием гостей мероприятия

---
## Сценарии применения
1. 🎤 **Press-Wall / Бренд-волл для фотозоны** — классика для конференций, форумов, корпоративных мероприятий, премий
2. 🎬 **Фон для сцены** — основное оформление сцены без светодиодных экранов или дополнение к ним
3. 📌 **Информационная/навигационная стена** — для зоны регистрации, программы мероприятия, списков спонсоров
4. 🎪 **Бренд-зона на выставке** — задняя стенка стенда компании
5. 🎨 **Имиджевые арт-объекты** — фигурные брусы как отдельные элементы оформления (например, колонны для СТС Kids)
6. 🚪 **Оформление входной зоны** — приветственный баннер при входе на мероприятие
7. 📺 **Каше для экрана** — обрамление светодиодных экранов на сцене (часто выполняется по той же технологии)

## Варианты исполнения
| Тип                     | Описание                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| **Прямой стандартный**  | Классический прямоугольный баннер с ровными краями                       |
| **Фигурный**            | Любая нестандартная форма (скошенные углы, вырезы, контурные элементы)   |
| **С дополнительными элементами** | Объемные буквы, неоновая подсветка, накладные элементы из ПВХ, акрила |
| **С фотопечатью 1440 dpi** | Максимальное качество изображения, идеально для крупных планов на фотографиях |
| **С матовой ламинацией** | Полное отсутствие бликов от вспышек фотоаппаратов, рекомендуется для пресс-воллов |
| **С боковой запечаткой** | Торец (боковая часть) также запечатывается в цвет основного дизайна для цельного вида |
