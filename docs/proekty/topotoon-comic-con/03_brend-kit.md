# Бренд-код Topotoon — фиксированный референс

Дата: 23.10.2026
Источник: презентация клиента `00_topotoon-x-comic-con.pdf`, рендеры `viz/`
Статус: **зафиксировано**. Использовать для всех материалов проекта: SketchUp-модель,
печатные макеты, визуализации, соцсети. Новые цвета и элементы не вводить.

---

## 1. Логотип

- Начертание: `top◉toon` — жирный гротеск, литера «o» заменена символом
  «◉» (кружок-шестерёнка с точкой). Читается как «topotoon».
- Варианты: чёрный на лаймовом; лаймовый на чёрном/фиолетовом; белый на фото.
- **Маскот**: «пламя-капля с глазами» — чёрный силуэт с цветной «начинкой»,
  крупные постановки (шапки, пол, гача) + паттерн-капли.
- Акцент-графика: чёрные «молнии»-зигзаги, скруглённые «капли»-иконки,
  лаймовые/фиолетовые диагонали.

| Цвет | HEX | Роль |

| **Фиолет электрик** | `#9060FC` – `#9C60FC` | второй акцент: гача, пуфы, лайтбоксы, диагонали |
| **Чёрный** | `#151720`, `#1D1D1D` | панели, пол, текст по лаймовому |

| **Белый** | `#FFFFFF` | плитка комбини, лайтбокс-короба, стеллажи |
| Зелёный капсульный | (по капсулам/колёсам тележки) | точечный акцент |

## 4. Типографика и ключевые тексты

- Заголовки — жирный гротеск, КАПС («МЫ ОТКРЫЛИСЬ!», «ТВОЯ СЛЕДУЮЩАЯ ИСТОРИЯ», «ПОДАРКИ ВНУТРИ»).
- Японский на лайтбоксах: `君の世界`, `セルフィ-камера`, `物語の世界`, `セルフィ`.
- Фразы: «МЫ ОТКРЫЛИСЬ!», «ТВОЯ СЛЕДУЮЩАЯ ИСТОРИЯ», «ЧИТАЙ ДАЛЬШЕ В TOPOTOON»,
  «ПОДАРКИ ВНУТРИ», «Кто ты из аниме-персонажей?».
- QR → сервис Topotoon.

## 5. Бренд-поведение в зонах

- Шапка каждого модуля: белый/лаймовый световой короб `top◉toon` + название отдела.
- Цоколи: белая плитка + лаймовая LED-подсветка снизу.
- Гача: 2 автомата (лайм + фиолет), шапка `top◉toon`, плакат «ПОДАРКИ ВНУТРИ»,
  маскот + молнии на бортах.
- Мерч: брендированная вода (белая этикетка + маскот), скретч-карты, флаеры,
  жетоны на пробную подписку → капсула.
