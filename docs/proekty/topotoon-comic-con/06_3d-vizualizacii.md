## Как пересобрать

```bash
pip install pillow numpy
python3 brand.py     # графика бренда и текстуры → tex/
python3 scene.py     # 6 кадров → renders3d/
python3 plan.py      # план сверху → renders3d/07-plan.png
```

Рендерится своим движком `engine.py`: перспектива, z-буфер,
попиксельный свет от 10 точечных источников, туман, блум, плёночный грейд.
Без Blender и GPU — весь набор собирается «чистым» Python за пару минут.

### Что менять

- **Ракурсы** — словарь `SHOTS` в `scene.py`.
- **Свет** — `scene_lights()`: позиция, цвет, мощность, радиус.
- **Материалы** — `SILVER`, `SILVER_D`, текстуры в `tex/`.
- **Зоны** — `build_zones()`: координаты в метрах, как на плане.
