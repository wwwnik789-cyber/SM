# Визуализации по презентации клиента — язык «японское комбини»

Дата: 27.10.2026
Основание: `00_topotoon-x-comic-con.pdf` (18 слайдов, презентация заказчика).
Геометрия — **без изменений**: 9,00 × 5,04 м · 11 столбов 100×100 · высота по
столбам 3 000 · обвязка 3 240 · подиум 50 мм · открытый фронт 9 м · левая и
задняя стены под брендинг.

Это **третий набор**, а не замена предыдущих:
- `renders3d/` — классическая тёмная серия (7 кадров, `06_3d-vizualizacii.md`);
- `renders3d-modern/` — светлый авторский минимализм (6 кадров, `07_`);
- **`renders3d-client/` — новый набор строго по презентации клиента (этот файл).**

Светлая серия как направление отменена заказчиком: «в основе у нас презентация
от клиента». Подача возвращается к комиксу из PDF — полутон, взрывные стикеры,
лаймовые шапки отделов, чёрные панели, полки-гондолы.

**Металл — царапанное серебро** (столбы, обвязка, рамы): в презентации металл
золотой, по ТЗ золото **не копируем**.

## Что добавляется в смету

По сравнению с классическим набором появляются позиции, которых не было:

1. **Гача-автоматы — 2 шт.** (0,62 × 0,55 × 1,52): корпус с печатью, прозрачный
   купол, механизм с ручкой, наполнение шарами.
2. **Телефонная будка** 0,84 × 0,68 × 2,24: каркас, 4 лаймовые панели,
   вывеска `top◉toon`, трубка, верхняя лаймовая шапка.
3. **Зеркало с неоновой рамкой** 0,96 × 2,02: зеркальное полотно, гибкий неон
   по периметру, надпись «МИР ИСТОРИЙ».
4. **Тележка для фото** 0,85 × 0,47 × 0,96 на колёсах + фон-плакаты 1,67 × 1,34.
5. **Полки-гондолы**: стеллаж 2,45 м с печатным фронтом (3 ряда товара),
   лаймовая кромка, цоколь.
6. **Экран «ТЕЛЕКАНАЛ TOPOTOON»** 2,15 × 1,21 в чёрной раме (вместо прежней
   ниши): LED-панель или печать + подсветка.
7. **4 пуфа** (2 лайм, 2 лаванда) с контрастными подушками.
8. Печать: 5 крупноформатных полотен (фриз 9 м, задняя стена 5 м, левая стена
   4,86 м, два фасада) + 12 малых (таблички, стикеры, касса, будка, гача).

Вычитается: прежняя ниша с обложками на задней стене и «портал» над входом.

## Как пересобрать

```bash
cd docs/proekty/topotoon-comic-con/viz3d
python brand_client.py      # 16 текстур в tex/cli_*.png  (~3 с)
python scene_client.py      # 6 кадров в ../renders3d-client/  (~2 мин)
python scene_client.py 04-lounge   # один кадр
```

Зависимости: Pillow, numpy (`/tmp/venv` в песочнице). Шрифты — из
`docs/ca-avtosalony/02_prezentaciya/fonts/`.

Правки сцены — только в `scene_client.py` (геометрия и `SHOTS`), правки
графики — в `brand_client.py` (размеры текстур). `scene.py` и `scene_modern.py`
не трогаются: это два прежних набора.
