# Современная версия визуализаций — те же чертежи, другой язык

Дата: 27.10.2026
Геометрия — **без изменений**, строго по модели `Topooton stand4.png`:
9,00 × 5,04 м · 11 столбов 100×100 · высота по столбам 3 000 · обвязка 3 240 ·
подиум 50 мм · открытый фронт 9 м · глухие левая и задняя стены.

Меняется только подача. Это второй вариант, а не замена первого:
классическая тёмная серия остаётся в `renders3d/`.

## Что именно изменилось в стиле

| Элемент | Классическая (тёмная) | Современная (светлая) |
|---|---|---|
| Окружение | чёрный зал, стенд-«остров» | нейтральная тёмная студия, стенд читается силуэтом |
| Стены | лаймовые светокороба, чёрные панели с плотной графикой | тёплый светлый камень, один крупный логотип, воздух |
| Столбы | царапанное серебро | анодированный алюминий, тонкий профиль |
| Фриз | лаймовый короб 9 м, высота 0,6 | тонкая светлая полоса 0,30 м с лого по центру |
| Лайм | заливка больших плоскостей | один точный акцент: линия на полу, кромка полки, козырёк будки |
| Пол | тёмный винил, лаймовая клякса с маскотом | светлый микроцемент, тонкая инкрустация от входа |
| Потолок | ламели шаг 0,30 | ламели шаг 0,42, между ними линейный свет |
| Свет | драматичный, контровой | мягкий рассеянный, дневной, с контактными тенями |
| Графика | плотные баннеры на всю стену | ниша с обложками, крупный логотип, подпись одной строкой |

Фирменный код сохранён: лого `top◉toon`, маскот, лайм `#CCF024`,
фиолет `#9060FC`, чёрный `#1A1B1F`.

## Что поменялось в конструкции

Геометрия каркаса не тронута. Изменились только отделочные слои —
их и считать в смете:

- **Столбы**: анодированный алюминий (профиль-накладка) вместо царапанного композита.
- **Стены**: натяжной текстиль с печатью по светлому фону вместо плотных баннеров.
  Площадь печати та же: 9 × 3 м и 5,04 × 3 м.
- **Фриз**: высота 0,30 м вместо 0,60 м — меньше материала и меньше веса.
- **Потолок**: ламели реже (шаг 0,42 м вместо 0,30) + линейные светильники между ними.
- **Пол**: светлый микроцемент (наливной или SPC с рисунком) вместо тёмного винила
  с полноцветной печатью — дешевле в печати, дороже в материале.
- **Подвесная рамка-портал** над входом: две алюминиевые стойки и перекладина.

## Как пересобрать

```bash
python3 brand_modern.py     # графика и текстуры светлой версии → tex/mod_*.png
python3 scene_modern.py     # 6 кадров → renders3d-modern/
python3 plan.py             # план общий для обеих версий
```

Ракурсы — словарь `SHOTS` в `scene_modern.py`, тот же, что в классической версии,
поэтому кадры сравниваются один к одному.

В движке `engine.py` добавлены **мягкие контактные тени** под мебелью
(параметр `occluders`) — без них светлая сцена выглядит «наклеенной».
