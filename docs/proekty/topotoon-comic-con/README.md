# Стенд «Комбини Topotoon» — Comic Con Игромир 2026

Проект стенда для сервиса аниме и вебтунов **Topotoon**: стенд-иммерсия
«японское комбини» с фотозонами, отделами аниме и вебтунов, телефонной будкой
и гача-автоматами.
