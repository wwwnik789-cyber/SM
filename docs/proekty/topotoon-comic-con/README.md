- Формат: стенд-«комбини», открытый фронт 9 м, глубина 6 м, высота столбов 3 м
- Подиум 9 × 6 м, толщина 5 см

- Палитра: лайм `#CCF024` + фиолет `#9060FC` + чёрный + царапанное серебро + белая плитка
- 9 зон по пути посетителя: вход-фото → вебтуны → аниме → неон-зеркало →
  телефонная будка → (опц.) тест-тачпад → касса → гача
