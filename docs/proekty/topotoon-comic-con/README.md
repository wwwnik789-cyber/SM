«японское комбини» с фотозонами, отделами аниме и вебтунов, телефонной будкой

## Ключевое

- Формат: стенд-«комбини», открытый фронт 9 м, глубина 5 м, высота столбов 3 м
- Подиум 9 × 5 м, толщина 5 см
- Каркас: брус 100×100, шаг 3,0 / 2,5 м (под раскрой 6-метровых), ламели 50×50
- Палитра: лайм `#CCF024` + фиолет `#9060FC` + чёрный + золото-хром + белая плитка
- 9 зон по пути посетителя: вход-фото → вебтуны → аниме → неон-зеркало →
  телефонная будка → (опц.) тест-тачпад → касса → гача
