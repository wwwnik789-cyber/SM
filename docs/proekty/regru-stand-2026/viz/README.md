# Визуализации стенда

Пять кадров, по одному на ключевой сценарий. Все — **концепт-рендеры**,
а не фотографии построенного стенда: их нельзя использовать как кейс
или как фотоотчёт.

| Файл | Что показано | Проверить при согласовании |

| [02-fotozona.jpg](./02-fotozona.jpg) | Фотозона 2,4 × 2,6 м с контражуром | Хватает ли холодного контражура, не «съедает» ли жёлтый лица |

## Что в кадрах намеренно не показано

- **Логотипы и надписи.** На всех плоскостях пусто: на момент рендера
  официального вектора логотипа не было. Это места под брендинг, а не
  финальный дизайн. Перед печатью подставляется логотип заказчика.
- **Точная геометрия пилонов.** На общем виде пилоны читаются массивнее
  проектных 240 × 240 мм — рендер снят широкоугольно, с искажением.
  Размеры брать только из `plan/plan-1-50.svg` и `plan/front-elevation.svg`.
- **Реальные люди.** Все персонажи — сгенерированные. Для пресс-материалов
  снимать реальных сотрудников и посетителей.

## Ракурсы для следующего круга

Если концепция согласуется, нужны ещё три кадра:

1. Вид сверху-сбоку (изометрия) — чтобы заказчик увидел пятно целиком.
2. Вечерний свет: стенд с включённым контражуром и LED-стеной в полумраке зала.
3. Кадр «в толпе»: стенд с 8–10 метра, как его видит человек из прохода.
