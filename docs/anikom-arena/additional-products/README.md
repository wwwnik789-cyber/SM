# Что ещё изготовить для «Аником Арены»

Рабочая гипотеза: у арены уже закрыты «крупные» носители — баннеры, пресс-воллы, навигация, фотозона. Следующий слой — то, что **зарабатывает на каждом матче**, **попадает в трансляцию** и **повторяется от турнира к турниру**.

Документ — предложение, а не смета. Размеры и цены уточняются после обмера.

## 1. Что мы знаем об объекте

| Параметр | Значение |
| --- | --- |

| Трибуна | 284 места под навесом |
| Раздевалки | 4, по 20 шкафчиков и 3 душа |

| Инфраструктура | кафе, медпункт, комментаторская, операторская, VAR |
| Загрузка | 151 команда, 3 500 игроков, 22 матча в неделю |
| События | 20+ турниров в год, женский чемпионат Москвы, две детские школы |
| Медиа | трансляция и запись каждого матча, вход свободный |

Два вывода, которые определяют предложение:

1. **Высокая частота.** 22 матча в неделю — это примерно 95 игровых дней в месяц, когда спонсорский инвентарь работает, а не лежит на складе.
2. **Есть тираж.** «Аником Групп» продаёт модель стадиона через «стадионокомплект»: новые арены в регионах будут повторять ту же планировку, а значит — ту же номенклатуру оформления.

## 2. Три фильтра для каждой позиции

- **Зарабатывает.** Позиция помогает продавать спонсорские пакеты, аренду или турниры.
- **В кадре.** Попадает в трансляцию, командное фото или соцсети.
- **Повторяется.** Даёт повторный заказ: сменная печать, тираж, комплект на новый стадион.

Позиция, которая не проходит хотя бы два фильтра, в список не попала.

## 5. Почему это выгодно арене

- **Спонсорский инвентарь — не расход, а продукт.** 12 периметральных модулей = 6 партнёров по два модуля. Вставки меняются, конструкция остаётся.
- **Частота усиливает цену.** 22 матча в неделю и трансляция каждого — это измеримый показ, который можно продавать.
- **Сменная печать — повторный заказ.** Титульные полосы турниров, вкладыши «Матч дня», состав команд, чехлы по сезону.
- **Тираж стадионов — самый крупный горизонт.** Один альбом решений продаётся вместе с каждым новым «стадионокомплектом»; брендинг интерьеров уже заявлен в пакетах «Арена» и «Про».

## 6. Чего не предлагаем

- **Светодиодный экран.** Уже есть; замена не окупается при текущем трафике.
- **Капитальные изменения фасада и кровли.** Требуют согласования с собственником и проекта.
- **Арт-объекты и скульптуры.** Дорого, не работают на спонсорский пакет.
- **Сувенирка без канала продаж.** Производство ради производства.
- **Дублирование навигации.** 20 табличек уже сделаны — новые позиции только дополняют систему.

## 7. Что нужно для расчёта

1. Обмер: ограждение по периметру, шаг стоек, высота, крепления.
2. Фото узлов: операторская площадка, скамейки, стойка ресепшен, стекло VIP-ложи.
3. Согласование с собственником: сверление, крепление к ограждению, электрика для подсветки.
4. Ветровая нагрузка для B2 и C1 — открытая площадка.
5. Календарь турниров на сезон — под тираж F1.

## 8. Следующий шаг

Выбрать 5 позиций из первой волны, снять размеры и подготовить смету. После этого — эскизы в фирменной системе: тёмно-синий, коралловый, сливовый и белый, логотип в кривых, без растровых зависимостей.
