# Фоны «Многоугольники» — своя серия

Авторские фоновые изображения SM-Production: гранёные полигональные плоскости,
тёмный графит, направленный свет. Не копия присланной текстуры — собственная серия
на той же пластике.

**Готовые файлы:** `poli/*.jpg` (1920×1080) и `poli-2x/*.jpg` (2560×1440).
**Всё одним архивом:** `SM-Fony-poli-JPEG.zip`.
**Обзор всех 8 вариантов:** `preview.jpg`.

Только JPEG. Никакого текста, логотипов и подписей внутри — чистые подложки.

## Как это сделано

Всё считается процедурно в numpy — готовая картинка нигде не растягивается,
поэтому фоны резкие на любом разрешении.

- **Мозаика (01, 04, 05, 07, 08)** — диаграмма Вороного по дрожащей сетке.
  Дрожание даёт неправильные многоугольники: пяти-, шести- и семиугольники,
  без повторов и без «обоев».
- **Материал** — грань + фаска со светом от направления `light` + тонкий тёмный шов.
  У каждой плиты своя яркость, иначе мозаика выглядит штампованной.
- **Перспектива (02)** — честная проекция: мировые координаты в метрах,
  камера на 4.5 м, плита 2.1 м. Ширина шва в пикселях пересчитывается по расстоянию,
  поэтому вдали нет муара, а вблизи швы не превращаются в чёрные полосы.
- **Низкополи (03)** — треугольники с реальными наклонами граней, свет по нормали.
- **Кристаллы (06)** — многогранники с пирамидальной вершиной, три плана резкости.
- **Зерно** 0,005–0,016 против бандинга на градиентах.

## Читаемость проверена цифрами

`contrast_report()` считает контраст текста в тех зонах, куда он реально ляжет.
Перед замером картинка слегка размывается: текст садится на локальное среднее,
а не на отдельный блик фасочного ребра — иначе метрика ловит шум, а не фон.

```
01-poli-mozaika      белый   6.8:1  OK
02-poli-perspektiva  белый   6.5:1  OK
03-nizkopoli         белый   6.4:1  OK
04-svet-diagonal     белый   5.5:1  OK
05-plitka-vertikal   белый   5.7:1  OK
06-obemnye-skol      белый  10.1:1  OK
07-svetlyy           тёмный  5.1:1  OK
08-akcent            белый  10.6:1  OK
```

Норма WCAG — 4.5:1 для обычного текста, 3:1 для крупного. Все восемь проходят.
На светлом `07` текст должен быть тёмным (`#0A0A0D`).

## Как пересобрать

```bash
pip install pillow numpy
python3 build_poly.py      # 8 фонов в двух разрешениях + preview + отчёт о контрасте
```

Сборка детерминирована: у каждой функции фиксированное зерно, повторный запуск
даёт те же файлы.

### Что менять

- **Масштаб плитки** — `cell` в каждой функции (в пикселях от ширины кадра
  или в метрах для перспективы).
- **Материал** — `face` и `gap` в `poly_rgb()`; `FACE` / `FACE_L` в начале файла.
- **Свет** — параметр `light` (доля вектора); меняет сторону, откуда падают блики.
- **Свечения и тени** — вызовы `glow()` в конце каждой функции.
- **Акцентный цвет** — `ACCENT` (#FF4D1C).
- **Разрешения** — кортеж в `main()`.

## Как использовать

1. Вставка → Рисунки → выбрать файл из `poli/`.
2. Правой кнопкой → «Изменить рисунок» → растянуть на слайд
   или задать как фон: Дизайн → Формат фона → Рисунок.
3. Нужен темнее — наложите прямоугольник `#0A0A0D` с прозрачностью 30–50%.
4. Для 4K берём `poli-2x/`.

Шрифты: Unbounded (заголовки) и Manrope (текст) — в `../ca-avtosalony/02_prezentaciya/fonts/`.
Палитра: фон `#0A0A0D`, карточки `#14141C`, текст `#F4F2EC`, акцент `#FF4D1C`, кислотный `#D8FF3E`.
