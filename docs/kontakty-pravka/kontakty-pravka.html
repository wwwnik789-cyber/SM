Страница «Контакты»: убрать Санкт-Петербург и добавить блок производства

Один файл, три небольших правки. Код можно копировать прямо отсюда кнопкой «Скопировать» — интернет, GitHub и доступы не нужны.

Ветка arena/57df9bb4-sm Коммит 817b219 3 файла React + Vite + Tailwind
Коротко, что меняется.
  • Страница контактов остаётся с одним адресом — Москва, Остаповский проезд, 9 с13. Питерский адрес, телефон +7 812 и вторая карта уходят.
  • Добавляется отдельный блок про производство: галерея цеха, шесть участков, чек-лист «что увидите на визите» и три шага, как попасть в цех.
  • В футере вместо петербургского адреса — режим производства.
  • В форме заявки тема «Визит на производство» больше не теряется.
Перед началом — сделайте копию. Сохраните исходные три файла рядом с проектом или переименуйте в Contacts.jsx.bak. Если что-то пойдёт не так, вернётесь к ним одной командой.
