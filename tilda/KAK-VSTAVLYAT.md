# Как пользоваться этой папкой (Тильда)

Здесь только материалы для копирования на ваш сайт на Tilda. Каталог React / роуты не трогаем.

## Что куда

| Папка | Что вставлять |
|-------|----------------|
| `01-brus-banner/` | Страница услуги «Брус-баннер» |
| `02-ofis-resepshn/` | Страница «Брендирование офисов и ресепшн» |
| `03-imidzhevye-fotozony/` | Страница «Имиджевые фотозоны» |
| `smm/` | Посты в соцсети (не на Тильду) |
| Картинки | `visualizations/brus-banners/`, `reception-zones/`, `photozones/` |

В каждой странице файлы пронумерованы: `01-...txt`, `02-...txt` — это порядок блоков сверху вниз.

## Как вставлять в Тильду

1. Создайте страницу → добавьте блоки по списку в `BLOKI.txt`.
2. Текст: блок **Т123 / Т142 / Т332** (заголовок + текст) — вставляйте содержимое `.txt` как есть.
3. Таблицы цен: блок **Т506** или **Т902** (таблица) — скопируйте строки; либо Zero Block.
4. Галерея: **Т368 / Т390** — загрузите jpg из папки визуализаций, подписи в файле `GALEREYA.txt`.
5. Кнопка заявки: привяжите к вашему попапу (`#popup:myform` или форму Тильды).
6. Обложка: **Т123 cover / Т228** 1920×700 или 1920×1080. Файл указан в `00-cover.txt`.

## Размеры картинок под Тильду

- Обложка страницы: 1920×800 или 1920×1080  
- Карточка услуги на главной: 800×600  
- Галерея: 1600 по длинной стороне (наши jpg уже ок)  
- Баннер анонса на главной: 1920×400
