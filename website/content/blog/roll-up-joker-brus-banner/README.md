# Статья: Roll-Up vs Джокер vs брус-баннер

Папка содержит готовый комплект для ручной публикации в блоге SM Production.

## Файлы

- `article.md` — полная статья с заголовками, таблицей, FAQ и CTA.
- `seo.json` — Title, Description, slug, canonical, alt-тексты и JSON-LD.
- `images/` — пять изображений 1200×675 px.

Статья также добавлена в локальную версию сайта:

- данные публикации: `website/src/data/blog.js`;
- обложка: `website/public/media/blog-roll-up-joker-brus-banner.jpg`.

## Перед публикацией

1. Подтвердить актуальность стартовых цен: 3 500 ₽, 9 000 ₽ и 16 500 ₽.
2. Подтвердить ориентиры времени монтажа для типовых размеров.
3. Проверить адрес страницы и canonical после создания публикации.
4. Сохранить только один H1.
5. Использовать alt-тексты из `seo.json`.

Никакие изменения в Tilda, Vercel или на действующем сайте автоматически не выполняются.
