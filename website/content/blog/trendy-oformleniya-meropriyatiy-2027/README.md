# Статья: тренды оформления мероприятий 2027 года

Готовый комплект для ручной публикации в блоге SM Production.

## Состав

- `article.md` — полная статья с front matter, таблицей трендов, девятью направлениями, практическими рекомендациями, чек-листом, FAQ и CTA;
- `seo.json` — Title, Description, slug, canonical, ключевые запросы, alt-тексты и JSON-LD `BlogPosting` + `FAQPage`;
- `research-notes.md` — редакционные заметки и список отраслевых материалов, использованных для проверки направления прогноза;
- `images/` — семь горизонтальных иллюстраций 1200×675 px.

Все изображения являются концептуальными иллюстрациями темы. Их не следует подписывать как реализованные проекты SM Production.

## Анонс для ленты блога

> В 2027 году оформление события превращается из набора декораций в цельный маршрут гостя. Разбираем девять практических трендов: единую сценографию, тактильные материалы, модульные системы, микрозоны, персонализацию, незаметный интерактив, световые сценарии и пространства, подготовленные для вертикального видео.

## Перед публикацией

1. Утвердить редакционную формулировку: материал опубликован как прогноз осенью 2026 года либо обновлён после наступления 2027 года.
2. Проверить итоговый URL и canonical.
3. Оставить на странице только один H1.
4. Загрузить изображения без изменения имён либо обновить пути в статье и `seo.json`.
5. Использовать alt-тексты из `seo.json`.
6. Проверить внутренние ссылки на страницы услуг, портфолио и контактов.
7. Добавить видимую кнопку заявки после заключительного CTA.
8. Проверить таблицу и изображения на мобильном устройстве.
9. При необходимости конвертировать JPEG в WebP средствами CMS, сохранив исходники.
10. После публикации обновить `dateModified`, URL изображения в JSON-LD и sitemap сайта.

Никакие изменения в Tilda, Vercel или на действующем сайте автоматически не выполнялись.
