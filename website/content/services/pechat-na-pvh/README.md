# Страница услуги «Печать на ПВХ»

Готовый комплект для ручной работы со страницей SM Production.

## Файлы

- `page.md` — полный текст страницы.
- `seo.json` — SEO Title, Description, slug, canonical, ключевые темы, alt и Schema.org.
- `design-spec.md` — структура и требования к дизайну страницы.
- `images/` — три изображения 16:9 без сгенерированных надписей.

Страница также добавлена в локальную версию сайта через `website/src/data/services.js`. Расширенные блоки и FAQ поддерживаются компонентом `website/src/pages/ServiceDetail.jsx`.

## Перед публикацией

1. Подтвердить используемые толщины ПВХ и доступность белой печати на конкретном оборудовании.
2. Подтвердить допустимые максимальные размеры листа и рабочего поля.
3. Добавить реальные фотографии производства после отбора.
4. Проверить адрес страницы и canonical.
5. Не публиковать фиксированную цену без актуального расчёта.

Никакие изменения в Tilda, Vercel или на действующем сайте автоматически не выполняются.
