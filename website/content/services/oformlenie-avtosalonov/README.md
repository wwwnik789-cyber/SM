# Страница «Оформление автосалонов»

Самостоятельный пакет для публикации и редактирования.

- `page.md` — расширенный текст посадочной страницы;
- `seo.json` — метаданные, ключевые запросы, alt-тексты и Service JSON-LD;
- `design-spec.md` — порядок блоков и визуальные требования;
- `images/` — шесть горизонтальных концепт-визуализаций.

Интегрированный маршрут сайта: `/uslugi/oformlenie-avtosalonov`.

Уникальная премиальная версия страницы реализована компонентом `website/src/pages/Dealerships.jsx`; она использует общую дизайн-систему и форму заявки нового сайта, но имеет отдельную автомобильную композицию и CTA «Заказать консультацию».

Перед публикацией необходимо подтвердить контакты, условия замера, сроки расчёта и доступность конкретных производственных услуг.
