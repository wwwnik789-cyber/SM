# SM Production — новая версия сайта

Отдельный проект для последовательной переработки сайта [sm-production.ru](https://sm-production.ru).

## Первый этап

1. Единая и понятная структура услуг без дублей.
2. Исправление текстовых, навигационных и технических ошибок.
3. SEO для каждой индексируемой страницы: уникальные title/description, canonical, Open Graph, JSON-LD, sitemap и robots.
4. Статическая генерация HTML для поисковых роботов и быстрых первых загрузок.

## Разработка

```bash
cd website
npm install
npm run dev
npm run build
npm run smoke
```
