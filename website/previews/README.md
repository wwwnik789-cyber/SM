# PDF-превью страницы «Оформление автосалонов»

- `SM-Production-dealership-page-preview.pdf` — восьмистраничное визуальное превью структуры и дизайна посадочной страницы;
- `build_dealership_page_preview.py` — сборщик PDF на ReportLab.

Превью показывает Hero, клиентский маршрут, три формата старта, зоны дилерского центра, работу с сетью адресов, процесс, консультационный CTA и FAQ. Это презентация дизайна страницы, а не браузерный скриншот и не опубликованный сайт.

Для сборки требуется `reportlab`; изображения используются из `website/public/media/`.
