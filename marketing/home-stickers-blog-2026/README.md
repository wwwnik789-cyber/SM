# Наклейки для дома на английском — публикационный пакет

Материалы к запуску набора обучающих наклеек (80 предметов, EN + RU). Используются для статьи в блоге и публикаций в соцсетях.

## Что здесь

| Файл | Что это |
|---|---|
| `og-cover-1200x630.png` | Обложка 1200×630 для статьи, ВК и Telegram-анонса |
| `instagram-1080x1350.png` | Вертикальная обложка 1080×1350 для Instagram и сторис |
| `build_blog_assets.py` | Генератор обложек: берёт иконки и шрифты из `production/home-stickers-bilingual/build_stickers.py` |

Тексты лежат рядом, в других папках:

- `site_content/10_blog-stikery-dom-anglijskij.md` — статья блога: SEO-настройки, тизер, текст, FAQ, JSON-LD;
- `smm/posts/stickers-home-launch.md` — девять постов, карусель, сценарий видео, сторис, календарь, хэштеги.

## Сборка картинок

```bash
.venv/bin/python marketing/home-stickers-blog-2026/build_blog_assets.py
```

## Что важно

- Обложки — макеты, а не фотографии работ. На сайте и в соцсетях не выдавать за фото готовой продукции.
- Цены в текстах не указаны: стоимость зависит от тиража и материала.
- Контакты и CTA единые: «Напишите — пришлём PDF» + 8 495 799-00-19.
- Палитра обложек совпадает с обложкой PDF: фон `#12100E`, текст `#F4EFE6`, акцент `#E9A552`, линия `#FF4D1C`.
