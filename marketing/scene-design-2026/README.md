# Оформление сцен — визуализации 2026

Концепт-кадры для страницы услуги «Оформление сцен», статьи в блоге и коммерческих
предложений. Все изображения — **визуализации, не фотографии объектов**. На
итоговых макетах стоит подпись «Визуализация · не фотография объекта».

| Файл | Размер | Где использовать |

| `raw/scene-04-welcome-zone.png` | 1408×768 | Welcome-зона: пресс-волл, стойка, кубы — рядом со сценой |

Обложка для блога: `public/media/scene-kashe-raus.jpg` (1200×630, кадр 01 в кропе
под OG).

## Параметры конструкции (проектные)

| Параметр | Значение |
|---|---|
| Габарит каше | 8000 × 4500 мм |
| Экран в свету | 6400 × 3000 мм |
| Зазор каше — экран | 200 мм |
| Толщина панели | 6 мм, композит |
| Глубина каркаса | 250 мм |
| Высота подиума | 600 мм |
| Раус | ткань с силиконовым кантом |
| LED-контур | лента 24 В, профиль с рассеивателем |

Размеры проектные — уточняются обмером площадки. Габарит 8000 × 4500 мм совпадает
с реализованным каше для дилерской конференции (см. `src/data/portfolio.js`).

## Сборка

```bash
python -m venv .venv && .venv/bin/pip install pillow
.venv/bin/python marketing/scene-design-2026/build_concept_plan.py
```

Скрипт берёт `raw/scene-01-kashe-dark.png`, собирает лист 1920×1080: спецификация
слева, визуализация справа с размерными линиями и выносками. Шрифт — Montserrat
Variable из `banners/anikom-arena-3000x2500-concepts/source/`.

## Что нельзя

- Выдавать кадры за фотографии выполненных объектов — только с подписью
  «визуализация».
- Ставить логотипы клиентов и надписи на конструкции без макета.
