# Креативы «Новогоднее оформление 2027»

## Формат 240 × 400 — основной для Директа

Папка [`240x400/`](./240x400), четыре файла, каждый **меньше 120 КБ**:

| Файл | Размер файла | Где использовать |
| --- | ---: | --- |
| `01-office-240x400.jpg` | 24,0 КБ | офис |
| `02-photozone-240x400.jpg` | 18,6 КБ | фотозоны |
| `03-corporate-240x400.jpg` | 20,4 КБ | корпоративы |
| `04-art-240x400.jpg` | 22,5 КБ | арт-объекты |

Композиция переработана под узкое полотно: фото занимает верхние 218 px, ниже — тёмно-синий блок с надзаголовком, заголовком, коралловым обещанием и пояснением. **Цен на креативах нет** — вместо них выгода и срок. Прошлая схема «панель слева, фото справа» при ширине 240 px оставляла под текст около 110 px — это нечитаемо, поэтому от неё отказались.

Проверка размеров и веса встроена в `validate.py`: скрипт падает, если файл больше 120 КБ или не равен 240 × 400.

Пересборка: `.venv/bin/python marketing/novogodnee-oformlenie-2027/creatives/build_240x400.py`

## Формат 1:1 и 16:9

Восемь файлов: четыре сюжета в двух пропорциях.

| Сюжет | 1:1 (1080 × 1080) | 16:9 (1920 × 1080) | Где использовать |
| --- | --- | --- | --- |
| Офис | `01-office-1x1.jpg` | `01-office-16x9.jpg` | группы G01, R01 |
| Фотозона | `02-photozone-1x1.jpg` | `02-photozone-16x9.jpg` | группы G02, N01 |
| Корпоратив | `03-corporate-1x1.jpg` | `03-corporate-16x9.jpg` | группы G03, N01 |
| Арт-объект | `04-art-1x1.jpg` | `04-art-16x9.jpg` | группы G05, N01 |

## Как устроены

- единая сетка: тёмно-синяя панель слева, фотография справа, коралловая линия на стыке;
- заголовок, подзаголовок, уточнение и цена-плашка;
- цен на креативах нет: вместо них обещание («Расчёт за 1 рабочий день», «Монтаж за 7 дней») и состав работ;
- шрифт Montserrat, начертания 500–800.

## Важно про изображения

Фотографии в `source/` — сгенерированные визуализации, а не съёмка реальных объектов SM Production. Они показывают тип и уровень оформления.

**Перед масштабным запуском** рекомендую заменить их на реальные фото новогодних проектов. Это самый сильный аргумент в нише: клиент узнаёт свой тип площадки.

**Нельзя** выдавать эти изображения за реализованные кейсы. В объявлениях они работают как иллюстрация формата, а не как портфолио.

## Пересборка

```bash
python -m venv .venv
.venv/bin/pip install Pillow
.venv/bin/python marketing/novogodnee-oformlenie-2027/creatives/build_creatives.py
```

Скрипт берёт фото из `source/` и шрифт из `banners/anikom-arena-3000x2500-concepts/source/`.

## Лимиты площадок

| Площадка | Формат | Примечание |
| --- | --- | --- |
| Яндекс Директ, РСЯ | 1:1, 16:9 | оба размера проходят |
| ВКонтакте | 1:1 | текст занимает менее 50% площади — требование модерации |
| Telegram-канал | 16:9 | превью поста |
| Сайт, блок «пакеты» | 1:1 | можно использовать как иллюстрации форматов |
