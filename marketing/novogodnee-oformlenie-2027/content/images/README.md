# Изображения контент-пакета «Новый год 2027»

Все картинки для блога, соцсетей и сайта в одном месте. 35 файлов, всё собирается скриптом из четырёх исходных фотографий.

## Где что лежит

| Папка | Что внутри | Куда идёт |
| --- | --- | --- |
| `blog/` | 4 обложки 1600×900 | блог сайта и карточки статей в Tilda |
| `social/1080x1350/` | 11 постов 4:5 | ВКонтакте, Instagram* |
| `social/1080x1080/` | те же 11 постов 1:1 | Telegram, квадратные превью |
| `stories/` | 5 карточек 1080×1920 | сторис и Reels-обложки |
| `site/` | герой 1920×1080 и 3 блока 1200×800 | страница новогоднего оформления |
| `preview/` | контактные листы | посмотреть всё сразу, не открывая десятки файлов |

Отдельно от сезона: `social/1080x1350/ny-image-neon-4x5.jpg`, `social/1080x1080/ny-image-neon-1x1.jpg` и `stories/ny-image-neon-1080x1920.jpg` — чистый кадр без текста (световое дерево из цеха). Собирается `build_social_newyear.py`, исходник в `content/source/ny-neon-tree.jpg`.

Копии обложек для сайта лежат ещё и в `public/media/` — оттуда их берёт `src/data/blog.js`.

## Как пересобрать

```bash
python3 -m venv .venv && .venv/bin/pip install -q Pillow
.venv/bin/python marketing/novogodnee-oformlenie-2027/content/build_images.py
```

Скрипт читает четыре фото из `creatives/source/` (lobby, photozone, corporate, art) и шрифт Montserrat из `banners/anikom-arena-3000x2500-concepts/source/`. Если поменять текст в словарях `POSTS` и `story()`, картинки пересоберутся с той же вёрсткой.

## Правила вёрстки

- **Никаких наездов текста.** Панель собирается снизу вверх: сначала считается нижний блок, потом обещание, и только остаток высоты отдаётся заголовку. Если места мало — сначала убирается подзаголовок, потом сжимаются отступы.
- **Читаемость в мелком размере.** Заголовок не мельче 36 px на 1080, кегль подписи — 17–19 px.
- **Фирменный локап** (черта + SM PRODUCTION) стоит на каждом макете, всегда в одном месте панели.
- **Матовая тёмная панель** вместо плашек поверх фото — текст не спорит с картинкой.
- **Цен нет.** Вместо них сроки и обещания: «Монтаж до 20 декабря», «Расчёт за 1 рабочий день», «Своё производство 750 м²».

## Что важно знать про фото

Исходники — постановочные интерьеры, а не съёмка наших объектов. Для соцсетей это нормально, но в блоге и на странице услуги лучше заменить их на реальные новогодние проекты, когда Диля пришлёт фотографии. Достаточно положить файл с тем же именем в `creatives/source/` и пересобрать.

## Тексты постов

Формулировки в картинках совпадают с `content/smm/posts-vk-telegram.md`. Если правится пост — правится и карточка, иначе в ленте будет расхождение.
