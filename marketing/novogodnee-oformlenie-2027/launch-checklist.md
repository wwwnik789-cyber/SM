# Чек-лист запуска: 90 минут

Выполняет Никита. Отмечать по порядку, ничего не пропускать.

## До старта (15 минут)

- [ ] Войти в Яндекс Директ под аккаунтом SM Production.
- [ ] Проверить, что к аккаунту привязан счётчик Метрики с сайта `sm-production.ru`.
- [ ] Проверить, что включён автоплатёж или на балансе есть первый платёж.
- [ ] Открыть `ads.csv`, `extensions.csv`, `keywords.csv`, `negative-keywords.txt` — это рабочая папка запуска.

## Метрика и amoCRM (15 минут)

- [ ] Отправить тестовую заявку с сайта.
- [ ] Убедиться, что цель `Заявка — форма` сработала в течение 2 минут.
- [ ] Убедиться, что заявка появилась в amoCRM.
- [ ] Проверить, что в сделке видны UTM-метки.
- [ ] Проверить клик по телефону и по Telegram.

**Если хотя бы один пункт не проходит — не запускать. Сначала чинить аналитику.**

## Страница (10 минут)

- [ ] Опубликованы блоки сроков и пакетов из `page-copy.md`.
- [ ] Исправлены опечатки.
- [ ] Кнопка первого экрана ведёт на форму, а не на «консультацию».
- [ ] Проверить страницу на телефоне: H1, сроки и цены видны без бесконечного скролла.
- [ ] Проверить скорость загрузки: Tilda-страница должна открываться быстрее 3 секунд на мобильном интернете.

## Кампании на поиске (30 минут)

- [ ] Создать 7 поисковых кампаний по структуре из `direct-campaign.md`.
- [ ] География: Москва и Московская область.
- [ ] Стратегия: ручное управление ставками, стартовые ставки из таблицы.
- [ ] Добавить фразы из `keywords.csv` по группам.
- [ ] Добавить общие минус-слова на аккаунт, групповые — в кампании.
- [ ] Загрузить объявления из `ads.csv` (по 2–3 на группу).
- [ ] Добавить быстрые ссылки и уточнения из `extensions.csv`.
- [ ] Указать ссылки с UTM-метками.
- [ ] Проверить, что в каждой группе есть хотя бы 2 объявления.

## РСЯ и ретаргетинг (10 минут)

- [ ] Создать ЕПК с комбинаторными объявлениями: 5 заголовков, 5 текстов, креативы из `creatives/`.
- [ ] Ограничить категории autotargeting.
- [ ] Создать ретаргетинг на посетителей страницы за 30 дней без заявки.
- [ ] Поставить бюджет: 30% РСЯ, 10% ретаргетинг.

## Финальная проверка (10 минут)

- [ ] Пройти по одному объявлению из каждой группы и проверить, что открывается правильный адрес.
- [ ] Проверить, что на странице нет 404 и битых ссылок.
- [ ] Убедиться, что в объявлениях нет запрещённых формулировок («лучший», «№1», «гарантия 100%»).
- [ ] Отправить кампании на модерацию.
- [ ] Поставить напоминание на завтра: проверить статус модерации и первые показы.

## Первые 24 часа после запуска

- [ ] Проверить, что кампании приняты модерацией.
- [ ] Посмотреть, есть ли показы и клики.
- [ ] Проверить отчёт «Поисковые запросы» и добавить первые минус-слова.
- [ ] Убедиться, что при первом клике Метрика фиксирует визит с UTM.

## Первая неделя

- [ ] Ежедневно: минус-слова, расход, аномалии.
- [ ] На третий день: отключить объявления с CTR ниже 1% на поиске.
- [ ] На седьмой день: первый отчёт по цене заявки и качеству.
- [ ] Решение: усиливать, чинить или останавливать каждую группу.
