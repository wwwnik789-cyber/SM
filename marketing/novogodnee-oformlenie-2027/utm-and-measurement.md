# Метки, цели и отчётность

## 1. UTM-схема

Для ссылок в объявлениях используем подстановки Директа — они подставляются автоматически:

```
https://sm-production.ru/novogodnee-oformlenie
?utm_source=yandex
&utm_medium=cpc
&utm_campaign={{campaign_name}}
&utm_content={{ad_id}}
&utm_term={{keyword}}
```

Если подстановки не поддерживаются в поле, используем статические метки:

```
?utm_source=yandex&utm_medium=cpc&utm_campaign=ng2027_search_office&utm_content=g01a1&utm_term=novogodnee_oformlenie_ofisa
```

### Правила

- `utm_source` — всегда `yandex`.
- `utm_medium` — `cpc` для поиска, `cpm` для РСЯ и ретаргетинга.
- `utm_campaign` — латиницей, по шаблону `ng2027_{тип}_{группа}`.
- `utm_content` — `ad_id` из `ads.csv`, чтобы связать заявку с конкретным объявлением.
- `utm_term` — ключевая фраза без пробелов, строчными.
- Якоря (`#pakety`) ставим до UTM-параметров: `/novogodnee-oformlenie#pakety?utm...` не работает, поэтому якорь используется только в объявлениях без меток, а в ссылках с метками — без якоря.

## 2. Цели в Метрике

| Цель | Тип | Что означает | Приоритет |
| --- | --- | --- | --- |
| `Заявка — форма` | JavaScript-событие | успешная отправка формы | ключевая |
| `Клик — телефон` | клик по номеру | звонок с сайта | ключевая |
| `Клик — Telegram` | клик по ссылке | переход в мессенджер | вспомогательная |
| `Заявка — звонок с формы` | JavaScript-событие | обратный звонок | вспомогательная |
| `Просмотр пакетов` | событие при скролле блока | вовлечение | аналитическая |

**Проверка перед запуском:** отправить тестовую заявку, убедиться, что цель срабатывает в режиме реального времени, и что заявка появилась в amoCRM.

## 3. Передача в amoCRM

В сделку должны попадать:

- `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`;
- страница первого визита;
- дата и время заявки;
- тип обращения (форма, звонок, мессенджер).

Если UTM не передаются, через две недели невозможно понять, какая группа приносит деньги. Это не «желательно», а обязательное условие запуска.

## 4. Еженедельный отчёт (понедельник, 15 минут)

| Показатель | Где смотреть |
| --- | --- |
| Расход по кампаниям | Директ |
| Клики, CTR, средняя цена клика | Директ |
| Заявки по целям | Метрика |
| Заявки в amoCRM | amoCRM |
| Расхождение Метрика / amoCRM | сравнение вручную |
| Цена заявки по группам | расчёт |
| Квалифицированные заявки | amoCRM, статус |
| Сделки и сумма | amoCRM |

**Красные флаги:**

- заявки в Метрике есть, в amoCRM нет → сломана передача;
- цена заявки выше 12 000 ₽ две недели → проблема в семантике или на странице;
- CTR ниже 2% на поиске → нерелевантные фразы или слабые заголовки;
- много заявок без ответа в течение 30 минут → проблема в обработке, не в рекламе.

## 5. Что сравниваем

Первый срез — через 14 дней:

- цена заявки по группам;
- доля квалифицированных;
- какие заголовки дают клики, но не заявки;
- какие запросы приходят фактически (отчёт «Поисковые запросы»).

Второй срез — через 30 дней: стоимость сделки и выручка на группу.

**Решение о продлении бюджета принимается по стоимости сделки, а не по цене клика.**
