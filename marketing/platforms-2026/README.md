# Где размещаться: каталоги, карты, реестры

Площадки, подобные [EventCatalog.ru](https://eventcatalog.ru), для продвижения
[sm-production.ru](https://sm-production.ru). Собрано и проверено 30.10.2026.

## Файлы

| Файл | Что это |
|---|---|
| `gde-razmeshchatsya-2026.pdf` | Основной документ: 10 страниц, четыре уровня площадок, что делать на каждой, пакет для размещения, план на 30 дней, деньги, UTM, чек-лист |
| `platforms.csv` | Реестр: 28 площадок с типом, условиями входа, действием и статусом |
| `listing-kit.md` | Готовые тексты для карточек: описания на 150 / 500 / 1500 знаков, категории по площадкам, три кейса, подписи к фото, UTM |
| `build_pdf.py` | Сборка PDF из `platforms.csv` и текстов |

## Коротко

EventCatalog.ru — B2B-каталог подрядчиков event-индустрии (в группе медиа Event.ru).
Карточка бесплатная, платят только за место в топе. «Подобные» площадки — это
четыре разных типа, и подход к ним разный:

1. **Каталоги event-индустрии** — 6 площадок. EventCatalog, AdIndex, Event.ru,
   EventBooking, AllAdvertising, Artist.ru. Вход почти везде бесплатный.
2. **Карты и справочники** — 9 площадок. Главные: Яндекс Бизнес и 2ГИС.
   Это единственный канал, который даёт звонки, а не просто показы.
3. **Реестры и аккредитации** — 5. Экспоцентр, Крокус, ВДНХ, НАОМ, РСВЯ.
   Не реклама, а допуск: без аккредитации на площадку не пустят.
4. **Медиа и сообщества** — 5. Event.ru, MICE&more, Sostav, отраслевые премии,
   Telegram-сообщества. Работает только кейс с цифрами.

## Что уже есть

- **Яндекс Карты:** карточка работает, 4.6, 16 оценок, 65 отзывов, 50 фото.
  Лучший актив из всего списка — надо не создавать, а дозаполнять.
- **EventCatalog:** карточки нет. Там есть «СИМ-продакшн» с доменом
  sim-production.ru — другая компания, название отличается одной буквой.
- Остальные площадки не проверялись — это первый спринт.

## Два расхождения на сайте

- `/team` — «производство в Москве и Санкт-Петербурге»; `/o-kompanii` — только
  Москва. Нужно одно утверждение на всех страницах, иначе каталоги разнесут
  разные факты, а в title останется город без подтверждения.
- Телефон: `8-495-799-00-19` на странице услуги, в каталогах принят
  `+7 (495) 799-00-19`.

## План

Первая неделя — 7 часов, 0 ₽: EventCatalog (две карточки), AdIndex,
EventBooking, Яндекс Бизнес, 2ГИС. Платное продвижение — только после трёх
обращений с бесплатной карточки. Ориентиры по деньгам в PDF, раздел
«Деньги: что и когда покупать».

## Пересобрать

```bash
python -m venv .venv
.venv/bin/pip install reportlab fonttools pymupdf
.venv/bin/python marketing/platforms-2026/build_pdf.py
```

Тексты правятся в `build_pdf.py`, данные о площадках — в `platforms.csv`
(колонка `short` — короткое описание для таблиц PDF).

## Ограничения

- Цены и условия — по страницам площадок на 30.10.2026. Тарифы меняются,
  перед оплатой сверять.
- Пометка «Не проверено» в `platforms.csv` означает: площадка существует и
  принимает размещения, но есть ли там карточка SM-Production и какая именно
  форма входа — нужно проверить вручную, нужен вход в аккаунт.
- Числа вроде «50–55 тыс. посетителей в месяц» — со слов самой площадки
  на её странице рекламы, не независимая проверка.
