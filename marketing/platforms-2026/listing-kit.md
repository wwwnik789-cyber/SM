## 8. UTM-метки

Единый шаблон, чтобы все размещения складывались в один отчёт.

    utm_source=<площадка>&utm_medium=catalog&utm_campaign=listing-2026&utm_content=<позиция>

| Площадка | utm_source |
|---|---|
| EventCatalog | eventcatalog |
| EventBooking | eventbooking |
| AdIndex | adindex |
| AllAdvertising | alladvertising |
| Artist.ru | artistru |
| Яндекс Бизнес и Карты | yandex_maps |
| 2ГИС | 2gis |
| Zoon | zoon |
| Orgpage | orgpage |
| Google Business | google_business |
| Авито | avito |
| Яндекс Услуги | yandex_uslugi |
| Медиа и кейсы | название издания |

`utm_medium` везде `catalog`, кроме карт (`organic`) и публикаций (`pr`).
Для звонков — отдельный номер или коллтрекинг, иначе половина заявок не
посчитается.
