# Настройка Яндекс Директа

## 1. До создания кампаний

- [ ] Страница `/b2b` обновлена и проверена на телефоне.
- [ ] Форма принимает описание, файл или ссылку на ТЗ.
- [ ] Метрика установлена на всех страницах.
- [ ] Созданы и проверены цели из `measurement-plan.md`.
- [ ] Метки сохраняются в карточке обращения.
- [ ] Назначены Анастасия и Диля, проверено распределение по очереди.
- [ ] Подтверждено обещание расчёта за 1 рабочий день.
- [ ] Есть политика обработки персональных данных.

## 2. Формат кампаний

Использовать режим эксперта и отдельные Единые перфоманс-кампании:

1. только поиск — горячие запросы о партнёре;
2. только поиск — конкретные услуги;
3. только рекламная сеть — повторный показ.

Для новых объявлений использовать актуальный формат комбинаторных объявлений. Не копировать старые рекомендации по текстово-графическим объявлениям без проверки интерфейса.

## 3. Поисковые кампании

- [ ] География: Москва и Московская область.
- [ ] Места показа: только поиск.
- [ ] Разделение по группам из `keywords.csv`.
- [ ] Не более 10–20 тесно связанных фраз в одной группе.
- [ ] Добавлен общий список исключений.
- [ ] Добавлены групповые исключения после просмотра прогнозируемых запросов.
- [ ] Автотаргетинг не оставлен без контроля: проверены категории и примеры запросов.
- [ ] Заголовки и тексты соответствуют конкретной группе.
- [ ] Ссылка ведёт на подходящий блок страницы.
- [ ] Метки добавлены.
- [ ] Быстрые ссылки проверены.
- [ ] Контактная информация организации заполнена.

## 4. Комбинаторные объявления

Для каждой группы использовать несколько самостоятельных элементов:

- до пяти заголовков из рабочего файла;
- три текста;
- изображения выполненных проектов для рекламной сети;
- логотип;
- призыв к отправке ТЗ;
- быстрые ссылки;
- уточнения.

Каждый заголовок должен быть понятен без соседнего заголовка. Не составлять фразу, которая имеет смысл только в одной комбинации.

## 5. Быстрые ссылки

После добавления якорей:

1. `Задачи` → `/b2b#services`
2. `Примеры работ` → `/b2b#cases`
3. `Как работаем` → `/b2b#process`
4. `Отправить ТЗ` → `/b2b#brief`
5. `Вопросы` → `/b2b#faq`
6. `Производство` → `/production`
7. `Портфолио` → `/portfolio`
8. `Контакты` → `/contacts`

Если якорей ещё нет, не использовать несуществующие адреса.

## 6. Уточнения

- Расчёт за 1 рабочий день
- Смета для вашей КП
- Производство и монтаж
- Документы для площадки
- Москва и область
- Один ответственный менеджер
- Возможна оптимизация проекта

## 7. Повторный показ

- [ ] Места показа: только рекламная сеть.
- [ ] Посетители `/b2b` без отправленной формы.
- [ ] Посетители портфолио или производства с глубиной от двух страниц.
- [ ] Начали форму, но не отправили.
- [ ] Исключены отправившие форму и действующие клиенты.
- [ ] Ограничена частота показов.
- [ ] Используются реальные фотографии работ, а не абстрактные изображения.

## 8. Модерация и проверка

- [ ] Ссылки открываются без ошибки.
- [ ] На странице есть заявленные услуги.
- [ ] Обещание расчёта сформулировано одинаково на странице и в объявлении.
- [ ] Нет неподтверждённых превосходных формулировок.
- [ ] Нет чужих товарных знаков без необходимости.
- [ ] Изображения не содержат мелкого нечитаемого текста.
- [ ] Все объявления прошли модерацию до назначенного запуска.

## 9. Первые две недели

Каждый рабочий день:

- смотреть поисковые запросы;
- добавлять исключения;
- проверять расход по группам;
- проверять цели;
- сверять обращения с карточками amoCRM;
- оценивать качество каждого обращения.

Не менять одновременно ставки, тексты, семантику и страницу: иначе невозможно понять причину результата.
