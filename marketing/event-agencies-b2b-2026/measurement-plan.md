# План аналитики

## 1. Что нужно связать

`реклама → визит → действие на странице → обращение → ТЗ → смета → выигранный проект`

Без последних четырёх статусов алгоритм будет искать дешёвые формы, а не полезные агентские проекты.

## 2. Цели Яндекс Метрики

| Код цели | Событие | Роль |
|---|---|---|
| `b2b_form_submit` | форма успешно отправлена | основная интернет-конверсия |
| `b2b_brief_upload` | загружен файл или добавлена ссылка на ТЗ | сильный сигнал качества |
| `b2b_form_start` | пользователь начал заполнять форму | диагностика страницы и повторный показ |
| `b2b_phone_click` | нажатие на телефон | дополнительная конверсия |
| `b2b_messenger_click` | переход в мессенджер | дополнительная конверсия |
| `b2b_primary_cta` | нажатие «Отправить ТЗ на расчёт» | диагностика первого экрана |
| `b2b_cases_view` | просмотр блока примеров | аудитория повторного показа |

Событие успешной формы отправляется только после подтверждённой передачи данных, а не при простом нажатии кнопки.

## 3. Статусы из работы менеджеров

| Статус | Когда ставить |
|---|---|
| `new` | обращение поступило |
| `contacted` | состоялся первый содержательный контакт |
| `qualified` | агентство или компания, есть реальная задача и срок |
| `brief_received` | получено ТЗ, эскиз или достаточное описание |
| `estimate_in_progress` | запрос передан на расчёт |
| `estimate_sent` | смета отправлена клиенту |
| `negotiation` | идёт согласование |
| `won` | заказ подтверждён |
| `lost` | проект проигран, указана причина |
| `nurture` | задача отложена, назначена дата следующего контакта |

## 4. Причины потери

- нецелевой частный запрос;
- нет ТЗ и срока;
- не подходит бюджет;
- не подходит срок;
- не подходит география;
- клиент выбрал другого подрядчика;
- тендер отменён;
- не удалось связаться;
- проект перенесён;
- другая причина с комментарием.

## 5. Рекламные метки

Базовый шаблон:

```text
utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_name}&utm_content={ad_id}_{position_type}_{position}&utm_term={keyword}
```

Для ВКонтакте:

```text
utm_source=vk&utm_medium=messenger&utm_campaign=b2b_event_agencies_warm&utm_content=manager_1
```

В ссылках нельзя передавать имя знакомого, телефон, название личной переписки и другие персональные данные.

## 6. Поля, которые должны сохраняться вместе с заявкой

- дата и время;
- источник;
- канал;
- кампания;
- группа;
- объявление;
- ключевая фраза;
- страница входа;
- ответственный менеджер;
- контакт;
- компания или агентство;
- дата мероприятия;
- краткое описание;
- ссылка на файлы;
- статус и причина потери.

## 7. Ценность целей для первого запуска

Это не финансовый доход, а начальные веса качества:

| Событие | Начальный вес |
|---|---:|
| форма отправлена | 1 |
| квалифицированное обращение | 3 |
| ТЗ получено | 5 |
| смета отправлена | 8 |
| проект выигран | фактическая валовая прибыль или согласованная ценность |

Не использовать эти веса как реальную выручку в отчётах.

## 8. Еженедельный отчёт

По каждой кампании и группе:

- расход;
- поисковые запросы;
- обращения;
- квалифицированные обращения;
- ТЗ;
- отправленные сметы;
- проекты в переговорах;
- выигранные проекты;
- причины потерь;
- следующий шаг.

## 9. Контроль качества

- один тест формы перед запуском;
- один тест звонка и мессенджера;
- проверка меток в карточке обращения;
- проверка, что повторная отправка страницы не дублирует цель;
- проверка исключения отправивших форму из повторного показа;
- ежедневная сверка сделок amoCRM с количеством обращений в Метрике.
