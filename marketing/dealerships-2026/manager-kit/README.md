# PDF-памятка для менеджеров

## Файлы

- `SM-Production-dealership-manager-playbook.pdf` — готовый внутренний документ;
- `manager-guide.md` — исходный текст;
- `build_manager_pdf.py` — сборщик PDF;
- `requirements.txt` — зависимости.

Памятка содержит сегментацию дилерских центров, три входных продукта, сценарии звонков, квалификацию, письмо, последовательность касаний, ответы на возражения, ограничения обещаний, передачу задачи в производство, CRM-стадии и KPI пилота.

Перед передачей менеджерам необходимо подтвердить актуальность контактов, срок предварительного расчёта, условия монтажа и ссылку на опубликованную страницу.
