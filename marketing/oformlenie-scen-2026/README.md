Два PDF и рабочие файлы к ним. Услуга: https://sm-production.ru/uslugi/oformleniye-stseny

## Что внутри

| Файл | Что это |
|---|---|

## Главное про страницу

- Страница собрана из шаблона «Каше для экрана»: пять блоков совпадают дословно, включая «паспорт фотозоны».
- Нет ни одного кейса с размерами, хотя в портфолио есть Mitsubishi с каше 8 × 4,5 м, «Новатэк» с тремя экранами и DECKHOUSE с 10+ локациями.
- Про цену и сроки — отписки. Ни одной цифры про сроки на всей странице.
- Нет ни одной внутренней ссылки: ни на «Каше», ни на «Раус», ни в блог.

## Главное про кампанию

- Три кампании: поиск (6 групп), ретаргетинг на посетителей страницы, мастер кампаний на тест.
- Поиск нельзя включать на широкие ключи: «сцена» — это кино, театр и игры. Поэтому 6 групп с разными лендингами и 130+ минус-слов.
- Санкт-Петербург выключен: город есть в title страницы, но монтаж заявлен по Москве и МО.
- Рекомендация на тест: 60 000 ₽/мес, из них 45 000 — поиск, 15 000 — ретаргетинг. Цифры по заявкам в PDF — оценка по рынку, а не прогноз Яндекса.

## Пересобрать

```bash
python -m venv .venv
.venv/bin/pip install reportlab fonttools pymupdf
.venv/bin/python marketing/oformlenie-scen-2026/build_pdfs.py
```

Правки текста — в `page-audit.md` и `direct-plan.md`. Разметка простая:

- `## Заголовок` — раздел, `### Заголовок` — подраздел
- `> текст` — цитата с сайта (серая плашка)
- `+ текст` — что вставить вместо (синяя плашка)
- `- текст` — пункт списка
- `! текст` — важное замечание (красная плашка)
- `**жирный**` — жирный внутри абзаца, таблицы markdown тоже поддерживаются

Данные кампании читаются из CSV: правите `keywords.csv` — пересобираете PDF.

## Ограничения

- Ставки и число кликов — рыночная оценка. Реальные цифры видны только в прогнозе бюджета внутри рекламного кабинета.
- Доступа к кабинету нет, и он не запрашивается: логин и пароль — это ваши деньги. Настройка идёт по документу, вручную.
- В объявлениях нет цен: на странице нет вилки, а обещать в объявлении то, чего нет на сайте, нельзя.
