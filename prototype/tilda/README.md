# Сниппеты для сборки страницы в Tilda

Готовые блоки из прототипа `/novogodnee-oformlenie`. Каждый файл — самодостаточный кусок HTML, который вставляется в Tilda через блок **T123 «HTML-код»** (кроме 01 — его можно вставить в настройки страницы → «Ещё» → HTML-код для `<head>`).

| Файл | Что делает | Куда вставлять |
|---|---|---|
| `01-global-css.html` | цветовые токены, кнопки, типографика, контейнер | один раз на странице (T123 или в `<head>` страницы) |
| `02-anchors.html` | липкое меню-пилюли по секциям | сразу под первым экраном |
| `03-before-after.html` | слайдер «до/после» на перетаскивании | в секции «до/после», по одному `<div class="ny-ba">` на пару фото |
| `04-prices.html` | 4 карточки тарифов | в секции цен (или штатный блок «Тарифы») |
| `05-faq.html` | аккордеон FAQ + автоматическая разметка FAQPage | в секции вопросов |
| `06-sticky-cta.html` | липкая панель «Позвонить / Смета» на телефонах | в самый низ страницы |
| `07-hero-stats.html` | три карточки с цифрами | под первым экраном |
| `08-jsonld-service.html` | разметка Service + BreadcrumbList | в самый низ страницы |

Пошаговая инструкция, карта «блок прототипа → блок Tilda» и подводные камни: `site_content/06_kak-sobrat-bloki-v-tilda.md`.

## Общие правила

- Все классы с префиксом `ny-` — чтобы не конфликтовать со стилями Tilda. Не переименовывайте.
- Внутри сниппетов нет внешних библиотек и шрифтов: шрифты подхватываются с сайта, при отсутствии — системный.
- Стили лежат внутри файла, поэтому порядок вставки не важен (кроме 01).
- Каждый сниппет можно вставить несколько раз на страницу (например, 03 — по одному на каждую пару фото).
- Картинки загружайте в Tilda и подставляйте ссылки из файлового менеджера; пары «до/после» — с одинаковым кадрированием.
