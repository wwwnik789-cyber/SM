# SM-Production — сайт 2026

Редизайн и полная пересборка сайта [sm-production.ru](https://sm-production.ru) (производство, изготовление и монтаж рекламных стендов, оформление мероприятий) на **React + Vite + Tailwind CSS v4 + Motion** в трендах 2026 года.

## Что внутри

**~45 страниц** (роуты): главная, каталог услуг (16) и страницы каждой услуги, производство (6 направлений), портфолио (12 кейсов) и страницы кейсов, процессы, калькулятор, аренда, SM-Media, B2B, о компании, команда, блог (10 статей) и статьи, отзывы, FAQ, материалы, вакансии, контакты, политика, карта сайта, 404.

### Тренды 2026
- **Bento-grid** раскладки и модульные карточки
- **Тёмная тема по умолчанию** + светлая (переключатель, сохраняется)
- **Glassmorphism 2.0** — только навигация и оверлеи
- **Кинетическая типографика** (Unbounded + Manrope, пословное появление заголовков)
- **Scroll-driven анимации**, sticky-элементы, scroll-progress, marquee-строки
- **«Перелистывание» страниц** — акцентная шторка при смене маршрута + spring-переходы
- **Таймлайн** процессов с прогресс-линией по скроллу
- Micro-interactions (sheen-кнопки, card-hover, cursor-glow), noise-оверлей
- Доступность: `prefers-reduced-motion`, aria-атрибуты, фокус-стили
- AI-readability: `llms.txt`, JSON-LD (LocalBusiness), `sitemap.xml`, `robots.txt`

### Фишки, которых не было на исходнике
- **Калькулятор-конструктор фотозоны** с живым SVG-предпросмотром в пропорциях и мгновенной сметой
- **Командная палитра** поиска по всему сайту (Ctrl/Cmd + K)
- **Мастер заявки** в 3 шага с валидацией
- Фильтры портфолио/услуг/отзывов/блога, поиск по статьям и FAQ
- Прелоадер, cookie-баннер, «наверх», тосты, карта сайта
- Энциклопедия материалов, таймлайн истории компании, вакансии

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # превью прод-сборки
node scripts/smoke.mjs  # SSR-смоук всех маршрутов
```

## Баннеры и печатные материалы

В репозитории лежит серия печатных баннеров «Кастинг» с подготовленными к
печати мастерами и производными версиями для сайта и соцсетей.

```
banners/casting-series/print/     печатные мастеры, JPEG, 300 dpi
public/media/banners/              веб-версии, 1600 px
public/media/banners/social/       1080×1920 · 1080×1350 · 1080×1080 · 1920×1080
docs/konstruktsii/banners/         спецификация и препресс-регламент
```

Пересборка и проверка QR-кодов:

```bash
pip install pillow numpy opencv-python-headless segno zxing-cpp
python3 scripts/banners/build_banners.py
python3 scripts/banners/jfif_density.py 300 banners/casting-series/print/*.jpg
```

Скрипт `build_banners.py` находит QR по finder-паттернам, восстанавливает фон
под кодом, вписывает рабочий QR версии 3 и **проверяет результат декодером** —
если код не считывается, об этом печатается предупреждение.

## Деплой на Vercel через GitHub

1. Запушьте репозиторий на GitHub (ветка `main`).
2. В Vercel: **Add New → Project** → импортируйте репозиторий.
3. Framework Preset: **Vite** (подхватывается из `vercel.json`: build `npm run build`, output `dist`).
4. SPA-роутинг уже настроен: `vercel.json` содержит rewrite `/(.*) → /index.html`.
5. Каждый пуш в `main` = продакшн-деплой, другие ветки = preview.

## Структура

```
src/
  components/  layout (шапка с мега-меню, футер, оверлеи) · ui · блоки
  data/        контент, перенесённый и адаптированный с исходного сайта
  lib/         pricing (формулы калькулятора), search, store (тема/модалки)
  pages/       25 компонентов страниц
public/media/  изображения проектов
```

Тексты и структура адаптированы с исходного сайта sm-production.ru. Изображения — сгенерированные визуальные заглушки в фирменной стилистике.
