# Презентация SM Production для автосалонов

Обновлённое предложение для дилерских центров: 10 слайдов, формат 16:9.

## Файлы

- `SM-Production-dealership-proposal-2026.pdf` — версия для отправки;
- `SM-Production-dealership-proposal-2026.pptx` — версия для PowerPoint;
- `presentation-preview.jpg` — превью всех слайдов;
- `presentation-copy.md` — тексты слайдов;
- `slides/` — отдельные PNG 1920×1080;
- `assets/` — изображения, логотип и производственные фотографии;
- `build_presentation.py` — генератор;
- `requirements.txt` — зависимости генератора.

## Основное отличие от первой версии

Презентация продаёт не общий список услуг, а три понятных сценария первого заказа: сезонное обновление, презентация модели и обновление пространства. Финальный слайд предлагает простой следующий шаг — экспресс-аудит по фотографиям и предварительный расчёт.

Концепт-визуализации помечены и не подаются как реальные кейсы.
