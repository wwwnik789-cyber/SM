# Концепция оформления «Аником Арены»

Клиентская презентация с предложением по развитию визуальной системы спортивной площадки.

## Основной файл

`Anikom-Arena-branding-concept.pdf`

- формат: PDF;
- размер страницы: 16:9;
- количество слайдов: 11;
- язык: русский;
- фотографии: только материалы, предоставленные пользователем;
- логотип «Аником Арены»: предоставленный PNG с прозрачностью;
- подготовлено как концептуальное предложение, а не финальная рабочая документация.

## Структура презентации

1. Обложка и позиционирование проекта.
2. Сильные стороны существующего оформления.
3. Карта потенциальных бренд-зон.
4. Система из трёх режимов: постоянный бренд, match-day, партнёры и события.
5. Концепция оформления главной трибуны и фасада.
6. Поле, медиа-башня и экран.
7. Навигация, раздевалки и входные пространства.
8. Пресс-зона, подиумы и точки для контента.
9. Модульный комплект временных конструкций.
10. Приоритеты запуска по этапам.
11. Переход к рабочему проекту.

## Визуальное направление

Палитра собрана на основе существующей среды арены:

- глубокий тёмно-синий;
- фирменный красный;
- белый;
- холодный серый и стальной.

Графическая система использует круглый знак арены, линии футбольного поля, модульные партнёрские блоки и крупную навигационную типографику.

## Важное ограничение

Все схемы и наложения являются концептуальными. Размеры, материалы, крепления, ветровые нагрузки, балласт, инженерные узлы, сроки и бюджет необходимо определить после выездного обследования и обмеров.

## Пересборка

```bash
python3 -m venv .venv
.venv/bin/pip install -r presentations/anikom-arena-branding/requirements.txt
.venv/bin/python presentations/anikom-arena-branding/build_presentation.py
```

Скрипт пересоздаёт PDF и общий лист предпросмотра `presentation-preview.jpg`.
