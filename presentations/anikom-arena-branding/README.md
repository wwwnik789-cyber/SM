# Предложение по оформлению «Аником Арены»

Клиентская презентация с конкретными местами установки, эскизами и понятным описанием конструкций. Основной акцент сделан на баннерах на плоских металлических рамках: показаны устройство рамки, зажим полотна по периметру и скрытое крепление к существующему ограждению.

## Основной файл

`Anikom-Arena-branding-concept.pdf`

- формат: PDF;
- пропорции страницы: 16:9;
- количество слайдов: 11;
- язык: русский;
- фотографии площадки и логотип предоставлены пользователем;
- примеры выполненных работ взяты из предоставленного прототипа;
- точные размеры существующих поверхностей подтверждаются обмерами на месте.

## Содержание презентации

1. Обложка.
2. Предварительный состав носителей.
3. Схема размещения всех носителей на главной трибуне.
4. Устройство плоской рамки: полотно, прижимные планки, металлическая основа и скрытые зажимы.
5. Балконная линия `К1`: деление рамок по стойкам ограждения.
6. Нижние модули `К2–К3` и носитель над центральным входом `К4`.
7. Эскиз и вид на месте баннера для телебашни `Б1`.
8. Два дополнительных пресс-волла `Ф1–Ф2` размером 3000×2500 мм.
9. Дополнительная фотозона `Ф3` размером 5000×3000 мм.
10. Четыре примера выполненных работ.
11. Итоговый состав и список данных для расчёта после обмера.

## Предлагаемый состав

- `Б1` — баннер телебашни, 1 шт.;
- `К1` — балконная линия из отдельных плоских рамок, 1 комплект;
- `К2–К3` — нижние модули главной трибуны, 2 шт.;
- `К4` — носитель над центральным входом, 1 шт.;
- `Ф1–Ф2` — дополнительные пресс-воллы 3000×2500 мм, 2 шт.;
- `Ф3` — дополнительная фотозона 5000×3000 мм, 1 шт.

## Решение для плоских рамок

1. Печатное полотно изготавливается с запасом по краям.
2. Прижимные планки удерживают полотно по всему периметру.
3. Плоская металлическая рамка собирается по размеру каждой зоны.
4. Рамка крепится к существующему ограждению скрытыми зажимами.
5. На лицевой стороне нет видимых шнуров, отверстий и крепежа.
6. Деление рамок, размеры и места зажимов уточняются после выезда на объект.
