# Конкретное предложение по оформлению «Аником Арены»

Переработанная клиентская презентация без общих рассуждений: схема размещения носителей, дизайн баннера телебашни, два дополнительных пресс-волла, фотозона 5×3 м, варианты полотен для плоских каркасов, примеры реализованных работ и предварительная ведомость.

## Основной файл

`Anikom-Arena-branding-concept.pdf`

- формат: PDF;
- пропорции страницы: 16:9;
- количество слайдов: 9;
- язык: русский;
- фотографии площадки и логотип: предоставлены пользователем;
- примеры реализованных работ: извлечены из предоставленного прототипа;
- все размеры существующих поверхностей подлежат подтверждению обмерами.

## Содержание презентации

1. Обложка и перечень конкретных решений.
2. Предварительный комплект носителей.
3. Схема размещения баннеров на плоских каркасах: F1–F4 и T1.
4. Дизайн и фотопривязка баннера для телебашни.
5. Два дополнительных пресс-волла формата 3000×2500 мм.
6. Дополнительная фотозона 5000×3000 мм.
7. Три типа сменных полотен для плоских каркасов.
8. Четыре примера реализованных работ SM Production.
9. Предварительная ведомость и список данных для точной сметы.

## Предлагаемый комплект

- `T1` — фронтальный баннер телебашни, 1 шт.;
- `F1` — балконная рекламная лента, 1 шт.;
- `F2–F3` — нижние модули главной трибуны, 2 шт.;
- `F4` — центральный вход, 1 шт.;
- `P1–P2` — дополнительные пресс-воллы 3000×2500 мм, 2 шт.;
- `P3` — фотозона 5000×3000 мм, опция.

## Технические оговорки

- размеры T1 и F1–F4 определяются только после обмеров;
- frontlit или mesh выбирается по условиям монтажа и ветровой нагрузке;
- крепления, кромка, люверсы, шнуровка и балласт рассчитываются после обследования;
- партнёрские логотипы необходимо получить в векторе;
- концепты не являются готовой рабочей документацией.
